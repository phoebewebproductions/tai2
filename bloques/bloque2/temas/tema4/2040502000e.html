5.2 COMPONENTES NOVEDOSOS DE WINDOWS

🪟

Las últimas versiones de Windows incorporan varios componentes que merecen ser destacados:

5.2.1 WINDOWS UAC (USER ACCOUNT CONTROL)

🔒

El Control de cuentas de usuario (UAC) es un componente de seguridad de los sistemas operativos Windows. UAC permite a los usuarios realizar tareas comunes como no administradores y como administradores pero sin tener que cambiar de usuario, cerrar sesión ni utilizar "Ejecutar como".

5.2.2 APPLOCKER

🔒

AppLocker es un programa destinado a crear reglas para permitir o denegar que las aplicaciones se ejecuten en función de identidades únicas de archivos y para especificar qué usuarios o grupos pueden ejecutar esas aplicaciones.

Permite:

  • • Controlar varios tipos de aplicaciones: archivos ejecutables, scripts, archivos del instalador de Windows, archivos DLL, y aplicaciones empaquetadas.
  • • Definir reglas basadas en atributos de archivo derivados de la firma digital.
  • • Asignar una regla a un grupo de seguridad o a un usuario individual.
  • • Crear excepciones a ciertas reglas.
  • • Usar el modo de solo auditoría para evaluar el impacto antes de aplicar.
  • • Importar y exportar reglas.
  • • Simplificar la creación y administración de reglas mediante Windows PowerShell cmdlets.

5.2.3 BITLOCKER

🔐

Programa de cifrado de disco disponible en las versiones Profesional, Ultimate y Enterprise de Windows Vista, Windows, Windows 10 y Windows 11 así como las versiones de servidor a partir de Windows Server 2008.

Características principales:

  • • Permite cifrar volúmenes enteros para proteger los datos.
  • • Utiliza por defecto el algoritmo de cifrado AES en modo CBC con claves de 128 bits.
  • • Implementa tres mecanismos de autentificación: modo de funcionamiento transparente, modo de autenticación de usuario, y modo en dispositivos USB.
🔒

TPM (Trusted Platform Module): Chip criptoprocesador seguro para almacenar las claves de cifrado de Windows.

Windows 11 requiere al menos TPM 1.2, aunque no necesariamente TPM 2.0.

5.2.4 WINDOWS DEFENDER

🛡️

Antivirus, Antispyware y firewall de Microsoft incluido y activado por defecto en Windows 8, 8.1, 10 y 11. También disponible para Windows 7 y Windows Vista como Microsoft Security Essentials.

5.2.5 WINDOWS SANDBOX

📦

Entorno aislado de escritorio para hacer pruebas ejecutando aplicaciones de forma segura. Disponible en Windows 10 Pro y Enterprise, pero no en Windows Home.

5.2.6 WINDOWS MIXED REALITY

🥽

Plataforma de realidad mixta y realidad virtual introducida como parte de Windows 10. Originalmente destinada para Microsoft Hololens, ahora se usa como plataforma para cascos de realidad virtual. Windows 11 finaliza la compatibilidad con Windows Mixed Reality a partir de la versión 24H2.

5.3 COMANDOS DE WINDOWS

5.3.1 COMANDOS DE ADMINISTRACIÓN

Comando Descripción
robocopy Copia archivos de una ubicación a otra.
gpedit.msc Editor de directivas de Grupo (GPO).
gpupdate Actualiza las políticas de grupo.
gpresult Muestra el resultado de las directivas de grupo aplicadas.
mmc Microsoft Management Console para administración de servicios.

5.3.2 COMANDOS DE RED

Comando Descripción
ping Comprueba la conexión y latencia de red.
tracert Traza la ruta de un paquete hasta su destino.
netstat Muestra estadísticas de protocolo y conexiones de red TCP/IP.
nbtstat Muestra estadísticas del protocolo y conexiones NBT.
ipconfig Muestra información de configuración TCP/IP.
route Manipula tablas locales de enrutamiento de red.
mstsc.exe Cliente de escritorio remoto de Windows (RDP).
