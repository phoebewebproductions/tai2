1.2. INTERFAZ DE USUARIO - SHELL

🖥️

Es el medio con el que el usuario interactúa con el equipo para controlar su funcionamiento. El Shell o intérprete de comandos es el programa informático que provee dicha interfaz.

Generalmente es la parte del sistema operativo que el usuario ve por lo que suelen ser fáciles de entender, amigables e intuitivos.

Las funciones principales de la interfaz de usuario son las siguientes:

🔄
Puesta en marcha y apagado
🎮
Control de las funciones manipulables del equipo
📁
Manipulación de archivos y directorios
🛠️
Herramientas de desarrollo de aplicaciones
🌐
Comunicación con otros sistemas
📊
Información de estado
⚙️
Configuración de la propia interfaz y entorno
🔄
Intercambio de datos entre aplicaciones
🔒
Control de acceso
❓
Sistema de ayuda interactivo

Según su construcción pueden ser de tres tipos:

🔌

Interfaz hardware

Utilizan dispositivos físicos para la entrada y salida de comandos de control e información al sistema operativo (teclado, ratón, pantalla, panel de control…)

💻

Interfaz software

Se utiliza para la salida de información generalmente a través de la pantalla.

🔄

Interfaz software-hardware

Traductor entre la máquina y las personas. Traduce la instrucción dada a código binario y el código binario a información legible.

Evolución

💻

CLI: Command Line Interface

Permite interactuar con el sistema a través de líneas de texto simples o de archivos de script. Ejemplos:

📝
COMMAND.COM
Intérprete de comandos de MS-DOS
📝
CMD
Intérprete de comandos de OS/2 y sistemas basados en Windows NT (Windows 2000, XP, 2003 Server, Vista, 7, 8, 8.1 y 10)
📝
Bourne Shell
Intérprete usado en las primeras versiones de Unix. Se convirtió en un estándar.
📝
BASH
Bourne-again Shell. Popular interfaz de comandos presente en Linux, Unix y Solaris.
📝
Emacs Shell/Eshell
Intérprete de comandos implementado en Emacs
📝
Z Shell /zsh
Potente intérprete de comandos para sistemas tipo Unix. Utilizado por MacOS Catalina
📝
C Shell/csh
Intérprete de comandos basado en C que es el lenguaje con el que está desarrollado Unix.
📝
TCsh
Versión mejorada de Csh.
📝
PowerShell
Intérprete de comandos de Windows destinado a competir con la potencia de los shells de Linux.
🖥️

GUI: Graphical User Interface

Permite interactuar con el sistema a través de un conjunto de imágenes y objetos gráficos. Ejemplos:

🖥️
GNOME Shell
Interfaz básica del entorno de escritorio GNOME presente en distribuciones Linux.
🖥️
KDE
Interfaz potente y multiplataforma orientada para competir con los mejores interfaces gráficos. Presente en Linux
🖥️
Unity
Entorno de escritorio basado en GNOME creado por la empresa Canonical para la distribución de Ubuntu.
🖥️
LXQt
Entorno de escritorio libre y de código abierto utilizado en Lubuntu en sustitución de GNOME.
🖥️
MATE
Continuación de GNOME 2 que cambió de nombre pare evitar conflictos con GNOME 3.
🖥️
Xfce
Entorno de escritorio libre para sistemas tipo Unix.
🖥️
Windows Luna
Interfaz gráfica de Windows XP
🖥️
Windows Aero
Interfaz gráfica de Windows Vista y Windows 7.
🖥️
Modern UI
Interfaz gráfica de Windows 8 y Windows Phone.
🖥️
Continuum
Interfaz gráfica incluida en el sistema operativo Windows 10.
👆

NUI: Natural User Interface

Interfaz natural de usuario. Permite interactuar con el sistema a través de movimientos gestuales del cuerpo, alguna de sus partes (como las yemas de los dedos en pantallas multitáctiles o las manos) o por reconocimiento de voz. Ejemplos:

🎮
Xbox Kinect
Sistema de control por movimiento para la consola Xbox
🗣️
Siri
Asistente virtual para IOS, macOS, tvOS, watchOS.
🗣️
Microsoft Cortana
Asistente virtual creado por Microsoft para Windows 10, Windows 10 Mobile, Windows Phone 8.1, altavoz inteligente Invoke, Windows Mixed Reality.
🗣️
Google Assistant
Asistente virtual desarrollado por Google disponible en los dispositivos móviles Google y Android y dispositivos domésticos inteligentes.
🗣️
Amazon Alexa
Asistente virtual desarrollado por Alexa utilizado por primera vez con el altavoz inteligente Amazon Echo.
