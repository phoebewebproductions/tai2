8.1. SISTEMAS OPERATIVOS PARA DISPOSITIVOS MÓVILES

Android

Android es el sistema operativo móvil más utilizado del mundo, con una cuota de mercado del 71% en el año 2023. iOS tiene una cuota de mercado de 28%.

Está basado en una versión modificada del núcleo Linux junto a software de código abierto. Fue diseñado para dispositivos móviles con pantalla táctil, smartphones, tabletas. Actualmente se utiliza en relojes inteligentes (Wear OS), automóviles (Android Auto y Android Automotive), televisores, consolas de videojuegos, cámaras digitales, etc.

Inicialmente fue desarrollado por Android Inc., empresa adquirida por Google en 2005. Android fue presentado en 2007 por la Open Handset Alliance.

El código fuente principal de Android es libre y open source, licenciado bajo Licencia Apache bajo el proyecto Android Open Source Project (AOSP).

Arquitectura Android

  • Kernel: Basado en Linux, permite aprovechar sus ventajas de seguridad y desarrollo de controladores.
  • Capa de abstracción de hardware (HAL): Proporciona interfaces estándares para exponer las capacidades del hardware.
  • Tiempo de ejecución de Android (ART): Entorno de ejecución que reemplazó a Dalvik desde Android 5.0.
  • Bibliotecas C/C++ nativas
  • Marco de trabajo de la API de Java: Conjunto de funciones del SO Android disponibles mediante APIs escritas en Java.
  • Apps del sistema: Conjunto de aplicaciones centrales para funciones básicas.

Novedades Android 12

  • Material You: Evolución de Material Design.
  • Wifi: Nueva acción "Cercano" para transferir credenciales de red.
  • Mejoras en la privacidad: Iconos para mostrar uso de cámara o micrófono.
  • AppSearch: Nuevo motor de búsqueda para encontrar archivos dentro de una aplicación.
  • Modo a una mano: Desplaza el contenido de la pantalla hacia abajo.
  • Doble toque recuperado: Vuelven las acciones rápidas.
  • Nuevos formatos de imagen y vídeo: Soporte para AVIF y HECVC.
  • Compatibilidad con NFC: Opción de abrir el coche con móviles compatibles con ultra wide band.
  • Optimización del rendimiento: Mejoras en la comunicación sistema-hardware.

iOS

Sistema operativo móvil de Apple Inc., originalmente desarrollado para iPhone. No permite su instalación en hardware de terceros.

iOS es un sistema operativo tipo Unix derivado de macOS, que a su vez está basado en Darwin BSD.

Arquitectura iOS

El sistema operativo iOS está distribuido en cuatro capas:

  1. Cocoa Touch: Capa superior, encargada de la interfaz gráfica.
  2. Media: Proporciona acceso a funciones multimedia.
  3. Core Services: Ofrece API para acceder a servicios principales del dispositivo.
  4. Core OS: El núcleo del sistema basado en Darwin.

Las aplicaciones para iOS se desarrollan con Xcode, el entorno de desarrollo integrado (IDE) de Apple. Xcode incluye la colección de compiladores del proyecto GNU (GCC) y puede compilar código C, C++, Swift, Objective-C, Objective-C++, Java y AppleScript.

Los desarrolladores pueden poner un precio por encima del mínimo ($0.99 dólares) a sus aplicaciones para distribuirlas en el App Store, de donde recibirán el 70% del dinero que produzca la aplicación.

La última versión de iOS es la 21C62 liberada en diciembre de 2022.
