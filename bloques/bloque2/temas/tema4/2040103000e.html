1.3. SISTEMA DE ENTRADA Y SALIDA

🔄

El sistema de entrada y salida (E/S) es un componente fundamental del sistema operativo que se encarga de controlar los dispositivos de E/S y la comunicación con los periféricos. Sus funciones principales incluyen:

  • 📌 Facilitar a las aplicaciones el uso de los dispositivos periféricos
  • 📌 Detectar y controlar los errores de los dispositivos
  • 📌 Optimizar la E/S del sistema
  • 📌 Proporcionar una interfaz común para diferentes tipos de dispositivos

Las operaciones de E/S pueden ocupar hasta el 30% del tiempo del Sistema Operativo, lo que resalta su importancia en el rendimiento global del sistema.

El sistema de E/S está compuesto por varios elementos clave:

🔌

Controladores de dispositivos (drivers)

Software que adapta las instrucciones genéricas del sistema operativo a las peculiaridades de cada dispositivo.

💾

Gestor de caché

Acelera y optimiza la E/S mediante la gestión de almacenamiento temporal.

🌐

Gestor de redes

Proporciona una interfaz homogénea para acceder a todos los sistemas de red del sistema operativo.

📁

Sistema de archivos

Controla cómo se almacenan y recuperan los datos en los dispositivos de almacenamiento.

Tipos de E/S

⏱️

E/S Síncrona

El programa queda bloqueado hasta recibir una respuesta.

🔄

E/S Asíncrona

El emisor continúa su trabajo después de enviar un mensaje.

💻

E/S Programada

La CPU está involucrada en la transferencia de cada byte.

⚡

E/S por interrupciones

La CPU es interrumpida cuando la transferencia está completa.

Mecanismos para mejorar el rendimiento de la E/S

🚀

Acceso Directo a Memoria (DMA)

Permite la transferencia de datos sin intervención constante de la CPU.

💾

Caché en el controlador de disco

Almacena temporalmente datos frecuentemente accedidos.

🧠

Caché de disco en memoria principal

Mantiene una copia de los datos del disco en la memoria RAM para un acceso más rápido.

⚡

Solapamiento de búsquedas y transferencias

Permite realizar múltiples operaciones de E/S simultáneamente.

📁

Sistema de archivos

El sistema de archivos es una parte crucial del sistema de E/S, encargado de organizar y gestionar los datos almacenados. Sus funciones principales incluyen:

  • 📊 Asignación de espacio a los archivos
  • 🗂️ Administración del espacio libre
  • 🔄 Proveer métodos para crear, eliminar, mover y renombrar archivos
  • 🔒 Implementar mecanismos de seguridad y control de acceso

Características avanzadas de los sistemas de archivos modernos

📔

Journaling

Un registro diario que permite restablecer datos en caso de fallos del sistema.

🔐

ACLs (Listas de Control de Acceso)

Permiten un control de acceso más granular a los archivos.

🏷️

Atributos extendidos

Permiten asociar metadatos adicionales a los archivos.

📊

Cuotas de disco

Limitan el espacio que puede usar cada usuario o grupo.
