5.1 SISTEMAS WINDOWS

Windows es una familia de distribuciones de sistemas operativos y aplicaciones asociadas, desarrollados por Microsoft para PC de escritorio, servidores, sistemas empotrados y antiguamente para smartphones. Actualmente, Windows es el sistema operativo más utilizado, disponible para varias arquitecturas incluyendo x86, x64 y ARM.

5.1.1 VERSIONES DE CLIENTE

  • Windows NT Workstation
  • Windows 2000 Profesional
  • Windows XP: Versión muy aceptada que incluyó mejoras en la interfaz, uso de varias sesiones y mejoras en velocidad y rendimiento.
  • Windows Vista: Presentó un diseño renovado con animaciones y transparencias, pero recibió críticas por inestabilidad y lentitud.
  • Windows 7: Gran actualización y mejora de Windows Vista, con mayor estabilidad y velocidad.
  • Windows 8: No fue bien recibida por la eliminación del botón de Inicio, pero introdujo una interfaz adaptada para pantallas táctiles.
  • Windows 10: Lanzada en 2015, ofrece una interfaz adaptable a ordenadores y dispositivos móviles.
  • Windows 11: Última versión, lanzada en octubre de 2021.

5.1.3 MODELOS DE LICENCIAS DE WINDOWS

5.1.3.1 TIPOS DE LICENCIAS DE CLIENTE DE WINDOWS

  • Licencias OEM: Preinstaladas en equipos nuevos, no transferibles.
  • Licencias Retail (RTL): Para usuario final, pueden ser completas o de actualización.
  • Licencias por volumen (GVLK): Para activaciones por lotes en empresas.

5.1.3.2 TIPOS DE LICENCIAS DE SERVIDOR DE WINDOWS

  • Licencia de Acceso Cliente (CAL): Por usuario o por dispositivo.
  • Licencia de Conector Externo (EC): Para acceso de usuarios externos.
  • Licencia por Core: Basada en el número de núcleos del procesador.
  • Licencias de servidores de especialidad: Para servidores específicos.
  • Licencias de servidores de administración (ML): Para administrar entornos de sistema operativo.
