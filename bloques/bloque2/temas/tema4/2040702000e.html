7.2. ESTRUCTURA DE DIRECTORIOS Y ADMINISTRACIÓN EN LINUX

Estructura de Directorios Básica (Filesystem Hierarchy Standard - FHS)

La estructura de directorios en Linux sigue un estándar conocido como FHS. Algunos de los directorios más importantes son:

📁
/
Directorio raíz
📁
/bin
Archivos binarios, ejecutables esenciales para todos los usuarios
📁
/sbin
Archivos binarios del SuperAdministrador
📁
/etc
Archivos de configuración del sistema estático no binarios
📁
/home
Contiene los directorios de trabajo de todos los usuarios salvo el root
📁
/root
Directorio home del superusuario root
📁
/var
Archivos de tamaño variable
📁
/tmp
Archivos temporales
📁
/usr
Aplicaciones para los usuarios
📁
/opt
Aplicaciones opcionales

Niveles de Ejecución (Runlevels)

Los sistemas Linux pueden arrancar en distintos modos de funcionamiento, conocidos como niveles de ejecución:

Nivel Nombre Descripción
0 Alto Apagado del sistema
1 Modo de usuario único (Monousuario) Nivel de ejecución mínimo orientado a reparar el sistema o para testeo
3 Multiusuario con soporte de red Inicia el sistema normalmente sin interfaz gráfica
5 Multiusuario gráfico (X11) Similar al nivel 3 pero con arranque automático de la interfaz gráfica
6 Reinicio Reinicio del sistema

Administración de Usuarios

Linux utiliza varios archivos importantes para la administración de usuarios:

  • 📄
    /etc/passwd
    Contiene la base de datos de usuarios
  • 🔒
    /etc/shadow
    Almacena las contraseñas de los usuarios de forma encriptada
  • 👥
    /etc/group
    Contiene la base de datos de grupos del sistema
  • 🔒
    /etc/gshadow
    Contiene las contraseñas encriptadas de grupo

Comandos de Administración de Usuarios

👤
useradd
Da de alta un usuario en el sistema
👥
groupadd
Da de alta un grupo
🔑
passwd
Permite cambiar la contraseña de un usuario

Seguridad de Ficheros

👤
chown
Cambia el usuario propietario de un archivo o directorio
👥
chgrp
Cambia el grupo propietario de un archivo o directorio
🔒
chmod
Modifica los permisos de un fichero/directorio
🎭
umask
Especifica la máscara de permisos del usuario

Permisos en Linux

El comando más utilizado para gestionar permisos es chmod. Puede usarse en modo relativo o absoluto:

Modo Relativo:

chmod u|g|o|a +|-|= r|w|x nombreFichero

Modo Absoluto:

chmod numeroPropietario numeroGrupoPropietario numeroOtros

FACL (File Access Control List)

Permite modificar la granularidad con la que se aplican los permisos de un fichero definiendo sus listas de control de acceso personalizadas.

📝
setfacl
Permite cambiar los permisos en las listas de control de acceso de un archivo o directorio
👁️
getfacl
Permite visualizar las FACLs asociadas a un fichero
