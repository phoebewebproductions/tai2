1.1. DEFINICIÓN Y ESTRUCTURA DE SISTEMA OPERATIVO

1.1.1. Definición de Sistema Operativo

Un Sistema Operativo es el software de un sistema que gestiona los recursos hardware y provee de servicios a los programas de aplicación abstrayendo al programador de tratar con el hardware directamente (actuando como una máquina virtual o extendida).

Es un intermediario entre el usuario y el hardware. Provee el soporte necesario para escribir los programas de aplicación mediante las llamadas al SO.

El Sistema operativo se ejecuta siempre en modo privilegiado o supervisor con respecto al resto.

La mayoría de aparatos electrónicos que utilizan microprocesadores llevan incorporado un sistema operativo.

Un sistema informático puede dividirse en cuatro componentes:

  • Hardware
  • Sistema Operativo
  • Programas de aplicación
  • Usuarios

1.1.2. Estructura de un Sistema Operativo

Un sistema operativo está compuesto por muchos componentes que pueden cambiar en función del sistema y de la arquitectura.

Generalmente los sistemas operativos suelen tener los siguientes componentes:

  • Kernel o núcleo
  • Interfaz de usuario
  • Controlador de dispositivo o driver
  • Sistema de archivos
  • Sistema de protección
  • Sistema de entrada y salida
  • Gestión de procesos
  • Gestión de memoria principal
  • Gestión de almacenamiento secundario
  • Sistema de comunicaciones
  • Gestor de recursos

1.1.2.1. Kernel o núcleo

Es un componente esencial del sistema operativo. Se ejecuta en modo privilegiado o modo núcleo en un área aislada para evitar que cualquier software malicioso pueda corromperlo.

No existe en algunos sistemas operativos, como por ejemplo en los sistemas empotrados, porque no todas las arquitecturas permiten distintos modos de ejecución.

Se encarga de:

  • Facilitar a los programas acceso seguro al hardware del sistema
  • Gestionar los recursos facilitando a las aplicaciones su uso mediante el servicio de llamadas al sistema.
  • Gestionar la multiprogramación (decide qué programa podrá usar un dispositivo de hardware y durante cuánto tiempo).
  • Proveer de abstracciones de hardware para ocultar la complejidad del hardware subyacente a los programadores de aplicaciones ofreciéndoles una interfaz limpia y uniforme del hardware subyacente.
