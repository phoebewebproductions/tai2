7. SISTEMAS GNU/LINUX

Denominación técnica y generalizada que reciben una serie de sistemas operativos de tipo Unix, generalmente de código abierto, multiplataforma, multiusuario y multitarea.

Están formados mediante la combinación de varios proyectos, entre los cuales destacan:

  • El núcleo de sistema operativo conocido como «Linux», encabezado por el programador finlandés Linus Torvalds.
  • El entorno GNU, encabezado por el programador estadounidense Richard Stallman junto a la Free Software Foundation, una fundación cuyo propósito es difundir el software libre.

Modelos de liberación y soporte

  • Liberación continua (Rolling release): Modelo de desarrollo de software donde el lanzamiento y las actualizaciones son continuas. Utilizado por Windows 10, OpenSuse, Gentoo Linux, Chromium OS…
  • Soporte a corto plazo STS (Short Term Support): Versiones del software diseñadas para tener soporte durante un año a partir de su fecha de publicación.
  • Soporte a largo plazo LTS (Long Term Support): Versiones del software diseñadas para tener soporte durante un tiempo más largo de lo normal. Por ejemplo, la versión de Ubuntu LTS tiene un soporte de 5 años mientras que la versión Ubuntu STS tiene un soporte de 9 meses.

Comandos de Linux

Linux es famoso por la potencia de su Shell. A continuación se presenta una clasificación de los comandos más importantes:

Comandos de propósito general

  • alias: Escribe un alias para la orden especificada
  • clear: Limpia la pantalla
  • echo: Salida de caracteres por pantalla
  • exit: Sale de un script/sesión/bucle
  • reboot: Reiniciar el sistema
  • shutdown: Apagar el sistema de forma parametrizada
  • man: Muestra el manual de un comando o fichero
  • su: Permite cambiar de usuario sin necesidad de cerrar la sesión
  • sudo: Permite a los usuarios ejecutar programas con los privilegios de seguridad de otro usuario

Comandos de operación de ficheros

  • cp: Copia un fichero
  • mv: Mover ficheros/directorios
  • ls: Lista los ficheros y directorios de un directorio
  • rm: Borra ficheros
  • mkdir: Crea el directorio
  • cd: Accede a un directorio
  • pwd: Muestra la ruta actual
  • find: Busca ficheros que coincidan con los parámetros especificados
  • grep: Buscar cadena en ficheros

Comandos de red

  • ifconfig: Ver configuración de red
  • ping: Realiza un echo request a la dirección indicada
  • tracert: Muestra la ruta que sigue un paquete hasta llegar a su destino
  • route: Permite mostrar y modificar la tabla de enrutamiento residente en el kernel
  • ssh: Secure Shell, para conexiones seguras
  • wget: Recupera contenido y archivos de un servidor web

Comandos de manejo de paquetes de instalación

  • rpm: Red Hat Package Manager
  • apt: Gestor de paquetes de las distribuciones basadas en Debian o Ubuntu
  • yum: Gestor de paquetes que mejora la instalación de paquetes rpm

Ficheros de red importantes

  • /etc/hosts: Resuelve los nombres de hosts que no pueden ser resueltos de ningún otro modo
  • /etc/resolv.conf: Especifica la dirección de los servidores DNS
  • /etc/sysconfig/network-scripts/ifcfg-nombre-interfaz: Proporciona información específica de una interfaz de red determinada
  • /etc/hosts.deny: Permite indicar qué equipos están denegados explícitamente para conectarse a varios servicios de red
  • /etc/hosts.allow: Permite indicar qué equipos están autorizados explícitamente para conectarse a varios servicios de red

Montaje de sistemas de ficheros

mount: Monta un dispositivo

mount -t vfat /dev/fd0 /mnt/floppy
  mount -t iso9660 /dev/cdrom /mnt/cdrom
  mount -t vfat /dev/hda1 /mnt/win
  mount -t vfat /dev/sdb1 /mnt/usb

umount: Desmonta la unidad

umount /dev/hda1
