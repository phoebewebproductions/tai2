7.3. TAREAS ADMINISTRATIVAS Y SCRIPTING EN LINUX

Programación de Tareas

En sistemas Unix/Linux, se utilizan los siguientes comandos para ejecutar tareas regularmente:

  • cron: Administrador regular de procesos en segundo plano.
  • at: Ejecuta un programa en un momento específico en el futuro.
  • batch: Similar a at, pero la tarea solo se ejecuta si la carga del sistema es inferior a 0.8.

cron

Archivos importantes:

  • /etc/crontab
  • /var/spool/cron/nombreUsuario
  • /etc/cron.d, /etc/cron.hourly, /etc/cron.daily, /etc/cron.weekly, /etc/cron.monthly

Formato de cada línea del archivo crontab:

Min. Hora Día-del-Mes Mes Día-de-la-semana Usuario Comando

Comandos útiles:

  • crontab -l: Lista las tareas especificadas en el crontab
  • crontab -r: Elimina las tareas programadas por el usuario
  • crontab -e: Edita el crontab

at

Sintaxis básica: at hora fecha comando

Ejemplos:

at now + 2 minutes
  at 16:00 today
  at 15:00 10/03/08

Comandos útiles:

  • at -l o atq: Visualiza tareas pendientes
  • at -d nº_trabajo o atrm nº_trabajo: Elimina tareas pendientes

Montaje de Sistemas de Archivos

Archivo /etc/fstab

Contiene información sobre el montaje de sistemas de archivos. Formato básico:

Dispositivo Punto-de-montaje Tipo-de-sistema Opciones Descargado Comprobado

Comando mount

Sintaxis básica: mount -t tipo origen punto_de_montaje opciones

Ejemplos:

mount -t iso9660 /dev/cdrom /mnt/cdrom
  mount -t vfat /dev/hdb5 /mnt/c -r

Para desmontar: umount punto_de_montaje

Almacenamiento Remoto

NFS (Network File System)

Protocolo estándar de compartición de ficheros de UNIX.

Exportar sistema de ficheros NFS (en /etc/exports):

/misc/export pc1.cetic.es(rw)

Montar cliente NFS:

mount servidorNFS:/directorio /directorioLocal opciones

Samba

Utiliza el protocolo SMB para compartir ficheros e impresoras.

Listar recursos compartidos:

smbclient -L ip -U usuario%contraseña

Configuración básica en /etc/samba/smb.conf:

[sharename]
  comment = Comentario
  path = /ruta
  valid users = usuario1 usuario2
  writable = yes

Programación Básica de Scripts en Linux

Estructura básica de un script:

#!/bin/bash
  
  # Comentarios
  # Código del script

Estructuras de Control

Bucle for:

for VAR in LIST
  do
    # cuerpo
  done

Condicional if:

if [ expresión ]
  then
    # código
  else
    # código
  fi

Bucle while:

while condicion
  do
    # comandos
  done

Definición de funciones:

function nombre_funcion {
    # código de la función
  }

Operaciones aritméticas:

let resultado=100/13
  resultado=$(expr 100 / 12)
