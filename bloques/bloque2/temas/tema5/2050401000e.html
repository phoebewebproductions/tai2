Algoritmos

Definiciones

Un Algoritmo es un conjunto ordenado y finito de operaciones que permite hallar la solución de un problema. No dependen del lenguaje de programación, y pueden expresarse en lenguaje natural, pseudocódigo o diagramas.

Características clave de los algoritmos:

  • Ordenado: indica el orden en que se ejecuta cada paso.
  • Finito: el algoritmo debe terminar en algún momento.
  • Determinista: si se sigue el algoritmo dos veces, se obtiene el mismo resultado.

Para problemas complejos, se utiliza el método "divide y vencerás", dividiendo el problema grande en porciones pequeñas que se puedan resolver individualmente.

Módulos, procedimientos y funciones

Los módulos son agrupaciones de pasos que resuelven un problema, facilitando la reutilización de código. Pueden recibir valores (variables) con los que operar para obtener un resultado.

En la programación estructurada, los módulos más comunes son:

  • Funciones: Reciben o no variables como parámetros de entrada y devuelven un único resultado.
  • Procedimientos: Pueden recibir variables de entrada y devolver varios, uno o ningún resultado.

Las variables declaradas dentro de procedimientos y funciones son Variables Locales, pertenecientes al contexto del subprograma. Las Variables Globales se definen en el ámbito del programa principal, aunque su uso está generalmente desaconsejado.

Cohesión y acoplamiento

Cohesión: Mide la relación entre las operaciones que ejecuta un módulo. Un módulo debe realizar una única tarea con un fin específico.

Acoplamiento: Mide la dependencia entre módulos. Se busca el menor acoplamiento posible para facilitar la reutilización y el mantenimiento del código.

Se debe buscar una alta cohesión en los módulos y un acoplamiento débil entre ellos.

Tipos de acoplamiento (de menor a mayor):

  1. De datos: comunicación mediante parámetros de datos simples.
  2. De marca: comunicación a través de estructuras de datos.
  3. De control: uso de variables de control en la comunicación.
  4. Externo: módulos ligados a componentes externos.
  5. Común: varios módulos referenciando un área común de datos.
  6. De contenido: un módulo accede o usa datos de parte de otro módulo.

Tipos de cohesión (de mayor a menor):

  1. Funcional: todos los elementos relacionados en una única función.
  2. Secuencial: empaqueta en secuencia varios módulos con cohesión funcional.
  3. De comunicación: elementos utilizan los mismos datos de entrada y salida.
  4. Procedimental: elementos relacionados que deben ejecutarse en un orden determinado.
  5. Temporal: tareas que deben realizarse en el mismo intervalo de tiempo.
  6. Lógica: tareas relacionadas de forma lógica.
  7. Casual: tareas con poca o ninguna relación entre sí.

Variables por valor y por referencia

Variables por valor: Se copian en el ámbito del subprograma. Las modificaciones durante la ejecución no afectan al valor original en el programa principal.

Variables por referencia: Se pasa la dirección de memoria del parámetro. Las modificaciones en el subprograma afectan al valor original en el programa principal.

Algoritmos recursividad vs iterativos. Backtracking

Algoritmos recursivos: Se llaman a sí mismos para resolver un problema. Tienen tres partes fundamentales: declaración, llamada recursiva y condición de parada.

Algoritmos iterativos: Utilizan sentencias iterativas (bucles) para resolver un problema.

Ejemplo de algoritmo recursivo (cálculo del factorial):


      Función factorialRecursiva(n)
        Si n = 1 → devuelve 1
        Sino devuelve n * factorial(n-1)

Ejemplo de algoritmo iterativo (cálculo del factorial):


      Función factorialIterativa(n)
        var resultado = 1
        while (n > 1) {
          resultado = n * resultado
          n = n - 1
        }
        Devuelve resultado

Backtracking: Algoritmo de vuelta atrás asociado al recorrido de pilas, colas y árboles. Enumera sistemáticamente todas las alternativas posibles en cada momento, probando una y manteniendo las demás en memoria.

Dificultades del backtracking:

  • Evitar caer en bucles infinitos
  • Evitar evaluar demasiadas alternativas (consumo excesivo de memoria)
  • Pueden ser lentos en su ejecución

Soluciones:

  • Aplicar funciones heurísticas
  • Usar podas para limitar el número de llamadas al algoritmo

Algoritmos de ordenación y búsqueda

Algoritmos de búsqueda más importantes:

  • Búsqueda secuencial sin centinela: Recorre un array comparando todos los elementos hasta encontrar el buscado.
  • Búsqueda secuencial con centinela: Añade el elemento a buscar al final del array para optimizar la búsqueda.
  • Búsqueda binaria: Requiere un array ordenado. Compara el elemento buscado con el central y divide la búsqueda en mitades.

Algoritmos de ordenación más importantes:

  • Método de la burbuja: Compara pares adyacentes y los intercambia si no están ordenados.
  • Método de selección: Divide el array en parte ordenada y desordenada, seleccionando el menor elemento de la parte desordenada en cada iteración.
  • Método de inserción: Toma elementos de la parte desordenada y los inserta en su posición correcta en la parte ordenada.
  • Quicksort: Divide la lista en dos partes usando un pivote, ordenando recursivamente cada parte.
