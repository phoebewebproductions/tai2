1.1. CARACTERÍSTICAS DE LOS SGBD

Definición de Base de Datos

Una base de datos es una colección de datos almacenados en un soporte informático no volátil de acceso directo. Estos datos deben estar:

  • Integrados: La definición y descripción de los datos deben ser únicas y estar integradas con los mismos datos.
  • Estructurados: Reflejando las interrelaciones y restricciones existentes en el mundo real.
  • Con redundancia controlada: No debe existir redundancia lógica aunque se permite redundancia física por motivos de eficiencia.
  • Relacionados: La base de datos debe almacenar las interrelaciones entre los datos y las restricciones semánticas.
  • Compartidos: Por diferentes usuarios y aplicaciones.
  • Independientes: De las aplicaciones que los utilicen tanto lógica como físicamente separando entre datos y tratamiento.

Sistema Gestor de Base de Datos (SGBD)

Un sistema gestor de base de datos (SGBD) es un conjunto de programas que establecen el método de organización necesario para el almacenamiento y la recuperación flexible de grandes cantidades de datos garantizando todas las propiedades definidas para una base de datos. A su vez permiten la modificación y extracción de la información mediante órdenes sencillas o algún lenguaje de consultas.

Funciones de los SGBD:

  • Mantener la integridad de los datos
  • Administrar el acceso de los usuarios a los datos
  • Recuperar la información si el sistema se corrompe
  • Presentar la información de la base de datos mediante generadores de informes y, la mayoría de las veces, un visor gráfico

Subsistemas de un SGBD

  • Motor de la base de datos: Acepta peticiones lógicas y las convierte en su equivalente físico.
  • Subsistema de definición de datos: Ayuda a crear y mantener el diccionario de datos y define la estructura del fichero.
  • Subsistema de manipulación de datos: Interfaz principal del usuario con la base de datos.
  • Subsistema de generación de aplicaciones: Contiene utilidades para ayudar a los usuarios en el desarrollo de aplicaciones.
  • Subsistema de administración: Ayuda a gestionar la base de datos ofreciendo diversas funcionalidades.

Características principales de los SGBD

  • Manejo de grandes volúmenes de datos
  • Manejo de accesos concurrentes
  • Escalabilidad y elevada capacidad de proceso
  • Alta disponibilidad
  • Seguridad y control de accesos
  • Integridad de los datos
  • Documentación
  • Flexibilidad
