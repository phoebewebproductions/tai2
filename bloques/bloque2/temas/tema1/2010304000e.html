3.4. DISPOSITIVOS DE ENTRADA Y SALIDA (E/S)

Los sistemas de entrada y salida permiten el intercambio de datos entre el sistema de información y el mundo exterior. Se trata de dispositivos periféricos, como los siguientes:

👤

a) Dispositivos de interfaz de usuarios

Como el ratón teclado, pantalla, impresora, etc.

Los dispositivos periféricos tienen formas de funcionamiento, velocidades de transferencia y formato de datos diferentes, sin embargo están todos identificados por la CPU de manera unívoca, y se sincronizan con ella para intercambiar información.

⬇️
⚙️

Para administrar los periféricos, la CPU usa módulos de entrada/salida comunes para cada gama de ellos, y cada dispositivo tiene un software específico llamado controlador o driver. Este controlador se encarga de adaptar las instrucciones que llegan al módulo de entrada a las peculiaridades del dispositivo.
