1.3. CARACTERÍSTICAS Y FUNCIONES DE LOS SISTEMAS DE INFORMACIÓN

1.3.1. CARACTERÍSTICAS DE UN SISTEMA DE INFORMACIÓN

Las características que definen a un sistema de información son las siguientes:

🎯

Relevancia

La información que almacenan los sistemas de información siempre debe ser relevante.

⏱️

Persistencia

La información puede permanecer en el sistema de forma indefinida.

🔄

Integración

Los diferentes componentes del sistema están integrados entre sí y comparten información e instrucciones de una manera ordenada.

⏩

Flujo de información

El sistema de información realiza sus funciones siguiendo un flujo de órdenes predeterminado.

🎮

Control

Un sistema de información sigue un procesamiento lógico, donde desde unas entradas se puede determinar una salida.

1.3.2. FUNCIONES DE UN SISTEMA DE INFORMACIÓN

Las funciones de un sistema de información son fundamentalmente las siguientes:

📥

Recopilación

Captura o recolecta datos en bruto tanto de los usuarios como de otros sistemas.

➡️
💾

Almacenamiento

Guarda de forma estructurada la información recopilada.

➡️
⚙️

Procesamiento

Convierte una entrada de datos en una salida mediante instrucciones.

➡️
📤

Distribución

Transfiere la información procesada a las personas o a otros sistemas.
