1.2. ELEMENTOS CONSTITUTIVOS DE UN SISTEMA DE INFORMACIÓN

Un sistema de información se puede definir como un conjunto de elementos que interactúan entre sí para conseguir un fin común. En un sistema de información nos podemos encontrar con los siguientes elementos:

💻

Hardware

Es la parte física del sistema de la información y la constituyen los equipos informáticos, así como sus componentes y periféricos. También se considera hardware a la arquitectura que acompaña a estos sistemas y que sirve para ubicarlos y garantizar su correcto funcionamiento.

Ejemplos:

  • 🖥️ Ordenadores y servidores
  • 🖨️ Impresoras y escáneres
  • 🔌 Componentes internos (CPU, RAM, discos duros)
  • 🖱️ Periféricos de entrada/salida
📊

Software

Es la parte lógica del sistema de la información, y se corresponde con el código que se ejecuta en el mismo. Hay diversos tipos de software, como sistemas operativos, bases de datos o programas de aplicaciones.

Ejemplos:

  • 🪟 Sistemas operativos (Windows, Linux, macOS)
  • 🗄️ Sistemas gestores de bases de datos
  • 📝 Aplicaciones ofimáticas
  • 🌐 Navegadores web y aplicaciones en la nube
🔄

Comunicaciones

Consistente en los equipos y la infraestructura que interconectan un sistema de la información con otros, formando redes de datos.

Ejemplos:

  • 📡 Routers y switches
  • 📶 Puntos de acceso WiFi
  • 🔌 Cableado de red
  • 📱 Dispositivos de comunicación móvil
📁

Datos

Que se considera la información a procesar o los resultados obtenidos por el sistema de información.

Ejemplos:

  • 📊 Datos estructurados en bases de datos
  • 📝 Documentos y archivos
  • 📈 Informes y estadísticas
  • 🔍 Metadatos y datos de configuración
👥

Personas

Que son todos los usuarios que se relacionan con el sistema de información, ya sea para operarlo o para administrarlo.

Ejemplos:

  • 👨‍💼 Usuarios finales
  • 👩‍💻 Administradores de sistemas
  • 👨‍💻 Desarrolladores
  • 👩‍🔧 Personal de soporte técnico
📋

Procedimientos o directivas

Que son pautas repetitivas para el gobierno del sistema de información.

Ejemplos:

  • 📜 Políticas de seguridad
  • 📝 Manuales de procedimientos
  • 🔄 Protocolos de actuación
  • 📊 Metodologías de trabajo
