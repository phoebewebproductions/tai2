3.2. LA UNIDAD CENTRAL DE PROCESAMIENTO (CPU)

La unidad central de procesamiento (CPU) o procesador constituye la parte central de un sistema de información, interpreta las instrucciones que normalmente se encuentran en un programa informático y procesa los datos de estas utilizando para ello operaciones básicas, aritméticas y lógicas.

3.2.1. CARACTERÍSTICAS DE LA CPU

Las características que diferencian a una CPU de otra son las siguientes:

⚡

Consumo energético

Se refiere a la cantidad de energía que consume la CPU al ejecutar acciones. Normalmente, a mayor capacidad de proceso, mayor consumo.

⏱️

Frecuencia de reloj

Se refiere a la velocidad de reloj que tiene una CPU y determina el número de acciones que puede ejecutar en un determinado periodo de tiempo. La frecuencia de reloj se suele medir en MHz o GHz y es un indicativo de la potencia de la CPU.

📏

Tamaño de palabra

Es el número de bits que maneja en paralelo el computador y que se refieren al ancho del bus de direcciones, lo cual define la arquitectura del ordenador.

🧩

Número de núcleos

Se trata de disponer en la CPU de dos o más núcleos o microprocesadores en un mismo paquete o circuito integrado que pueden repartir las instrucciones entre ellos y trabajar de forma paralela. Cada uno de los núcleos dispone de su propia memoria caché L1. Actualmente hay procesadores de 2 a 64 núcleos.

🧵

Número de hilos

Dentro de cada núcleo las operaciones se pueden dividir en hilos (threads) que pueden ejecutarse simultáneamente. Es el equivalente a disponer de varios núcleos virtuales.

💾

Capacidad de memoria cache

La capacidad de la memoria caché determina la necesidad de acceder a la memoria RAM, y por tanto, la velocidad del procesamiento.

⚡

Rendimiento o potencia

Se trata del número de operaciones que puede ejecutar una CPU, y normalmente se mide en FLOPS (Floating-point Operations per second), esto es número de operaciones en punto flotante por segundo. También se suele usar MIPS (Million Instructions per second), millones de instrucciones por segundo.

3.2.2. COMPONENTES DE LA CPU

Los principales componentes de la CPU son:

Componentes principales de una CPU
🎮
Unidad de Control (UC)
Recibe y ejecuta las instrucciones, que interpreta y procesa mediante órdenes que envía a otros componentes.
🧮
Unidad Aritmético Lógica (UAL/ALU)
Encargada de realizar las operaciones de tipo aritmético y de tipo lógico.
📋
Conjunto de Registros
Memoria de alta velocidad y poca capacidad para guardar valores de datos, comandos, instrucciones o estados.
💾
Memoria Caché
Memoria de alta velocidad donde se almacenan los datos para que la CPU no tenga que acceder a la memoria principal.
🔢
Unidad de Punto Flotante (FPU)
Unidades integradas para efectuar operaciones matemáticas en punto flotante.
🔍
Unidad de Gestión de Memoria (MMU)
Circuito integrado específico que forma parte del hardware de la CPU.

3.2.3. FUNCIONAMIENTO DE LA CPU

RISC (Reduced Instruction Set Computer) y CISC (Complex Instruction Set Computer) son dos tipos de diseño de CPU:

🔄

RISC

  • Instrucciones cortas de tamaño fijo
  • Instrucciones de un único ciclo
  • Solo las instrucciones de carga y almacenamiento acceden a la memoria de datos
🔄

CISC

  • Conjunto de instrucciones amplio y complejo
  • Permite operaciones complejas entre operandos situados en la memoria o en los registros internos

Una instrucción de la CPU pasa por las siguientes fases:

1

Fase de captación o fetch

La CPU obtiene la instrucción de la memoria

➡️
2

Fase de decodificación o decode

La CPU interpreta la instrucción

➡️
3

Fase de ejecución o execute

La CPU realiza la operación indicada

➡️
4

Store o almacenamiento

La CPU guarda el resultado

Los principales modos de direccionamiento son:

🔍

Implícito

La instrucción no especifica el operando, está implícito en la operación

📌

Inmediato

En este modo el operando está incluido directamente en la instrucción

🎯

Directo o absoluto

La instrucción contiene la dirección de memoria donde está el operando

🔄

Indirecto

La instrucción contiene la dirección de memoria donde está la dirección del operando

🧵

Multihilo (Multithreading)

Consiste en la división de un proceso en hilos que pueden ejecutarse en una o varias CPUs de manera simultánea. Tipos principales:

  • 🔄 Multihilo simultáneo (SMT)
  • ⏱️ Multihilo temporal (TMT)
🖥️

Multiprocesamiento

Consiste en la ejecución de varios procesos a la vez de forma simultánea en varios procesadores o núcleos. Tipos principales:

  • ⚖️ Procesamiento Asimétrico (AMP)
  • 🔄 Procesamiento Simétrico (SMP)
  • 🔍 Acceso no uniforme a Memoria (NUMA)
  • 🚀 Proceso paralelo masivo (MPP)
