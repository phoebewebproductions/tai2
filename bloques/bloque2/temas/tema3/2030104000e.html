Formatos de información y ficheros

Los datos que se manejan en Memoria Principal necesitan ser almacenados en un medio persistente para estar disponibles en el futuro, o porque es necesario utilizar la memoria que utilizan para otros procesos.

Los ficheros pueden clasificarse:

  • Según su contenido: De datos o de programas.
  • Por la forma de almacenamiento: Binarios (como imágenes, pdf, etc.) o de texto (cadenas de caracteres: csv, texto plano, etc.)

Los ficheros de datos, al almacenarse en un soporte podrán ser interpretados por unos u otros programas, según su definición. De esta forma, se crean ficheros de texto, de datos, de imágenes, de video, etc. Es habitual dotarlos de una extensión o tipo de archivo para poder identificarlos fácilmente.

La Administración General del Estado ha publicado una Norma Técnica de Interoperabilidad en la que informa qué tipos de archivo son admitidos por las Administraciones. Existen muchos tipos de archivo más, pero esta guía es una buena forma de identificar cuáles son los más importantes.

Tipos de archivos admitidos por las Administraciones:

  • CAdES (CMS Advanced Electronic Signatures): Formato de firma electrónica avanzada basado en CMS. Se utiliza para garantizar la autenticidad e integridad de los documentos digitales.
  • CMS (Cryptographic Message Syntax): Estándar para cifrar y firmar mensajes. Se usa en comunicaciones seguras y firmas digitales.
  • PAdES (PDF Advanced Electronic Signatures): Formato de firma electrónica avanzada para documentos PDF. Asegura la validez legal de los PDF firmados.
  • PDF Signature: Firma digital incorporada en archivos PDF para garantizar su autenticidad e integridad.
  • PKCS#7 (Public Key Cryptography Standards #7): Estándar para firmar y cifrar datos. Usado en certificados digitales y firmas electrónicas.
  • XAdES (XML Advanced Electronic Signatures): Formato de firma electrónica avanzada para documentos XML. Asegura la autenticidad e integridad de datos en formato XML.
  • XML-DSig (XML Digital Signature): Estándar para firmar digitalmente documentos XML. Garantiza la autenticidad e integridad de los datos.
  • TLS (Transport Layer Security): Protocolo de seguridad para comunicaciones en red. Protege la privacidad e integridad de los datos transmitidos.
  • Base16, Base32, Base64: Esquemas de codificación binaria a texto. Se usan para representar datos binarios en formatos legibles.
  • ISO/IEC 26300:2006: Estándar para el formato de documentos OpenDocument (ODF). Usado en suites ofimáticas como LibreOffice.
  • OASIS 1.2: Estándar para documentos de texto enriquecido. Usado en intercambio de documentos entre aplicaciones.
  • Strict Open XML: Variante estricta del formato Open XML. Usado en documentos de Microsoft Office.
  • PDF, PDF/A: Formato de documento portátil (PDF) y su variante para archivo a largo plazo (PDF/A). Usado para documentos digitales que preservan el formato.
  • PNG (Portable Network Graphics): Formato de imagen sin pérdida. Usado para gráficos y imágenes en la web.
  • RTF (Rich Text Format): Formato de texto enriquecido. Usado para intercambiar documentos entre aplicaciones de procesamiento de texto.
  • SVG (Scalable Vector Graphics): Formato de gráficos vectoriales. Usado para imágenes escalables en la web.
  • TIFF (Tagged Image File Format): Formato de imagen de alta calidad. Usado en fotografía y escaneo de documentos.
  • TXT: Formato de texto plano. Usado para almacenar y compartir texto sin formato.
  • XHTML (Extensible HyperText Markup Language): Versión XML de HTML. Usado para páginas web estructuradas.
  • MP3, MPEG-1 Audio Layer 3: Formato de compresión de audio. Usado para almacenar y transmitir música y sonido.
  • NTP (Network Time Protocol): Protocolo para sincronizar relojes en redes. Usado en sistemas que requieren precisión de tiempo.
  • OCSP (Online Certificate Status Protocol): Protocolo para verificar el estado de certificados digitales. Usado en infraestructuras de clave pública (PKI).
  • SOAP (Simple Object Access Protocol): Protocolo para intercambiar información en servicios web. Usado en comunicaciones entre aplicaciones.
  • UDDI (Universal Description, Discovery, and Integration): Estándar para registrar y descubrir servicios web. Usado en arquitecturas orientadas a servicios (SOA).
  • WSDL (Web Services Description Language): Lenguaje para describir servicios web. Usado en la definición de interfaces de servicios.
  • WS-Security: Estándar para seguridad en servicios web. Usado para proteger mensajes SOAP.
  • ASN.1 (Abstract Syntax Notation One): Estándar para representar datos. Usado en telecomunicaciones y protocolos de red.
  • OID (Object Identifier): Identificador único de objetos en sistemas de información. Usado en PKI y otros sistemas.
  • URI, URL, URN: Identificadores de recursos en la web. Usados para localizar y nombrar recursos en internet.
  • UCS, UTF (Universal Character Set, Unicode Transformation Format): Estándares de codificación de caracteres. Usados para representar texto en diferentes idiomas.
  • RFC 4646: Estándar para etiquetas de idioma. Usado en internacionalización y localización.
  • ISO 639: Estándar para códigos de idiomas. Usado en la identificación de lenguas.
  • GML (Geography Markup Language): Formato para representar datos geográficos. Usado en sistemas de información geográfica (GIS).
  • WFS, WMS (Web Feature Service, Web Map Service): Servicios web para datos geográficos. Usados en aplicaciones de mapas y GIS.
  • GZIP, ZIP: Formatos de compresión de archivos. Usados para reducir el tamaño de archivos y agrupar varios en uno.
  • AVI (Audio Video Interleave): Formato de archivo multimedia. Usado para almacenar video y audio.
  • MPEG-4, MP4 media: Formatos de compresión de video y audio. Usados en streaming y almacenamiento de multimedia.
  • CSV (Comma Separated Values): Formato de texto para datos tabulares. Usado en intercambio de datos entre aplicaciones.
  • HTML (HyperText Markup Language): Lenguaje para crear páginas web. Usado en la estructuración de contenido web.
  • CSS (Cascading Style Sheets): Lenguaje para estilizar páginas web. Usado en el diseño visual de sitios web.
  • JPEG (Joint Photographic Experts Group): Formato de compresión de imágenes. Usado en fotografía digital.
  • MHTML (MIME HTML): Formato para archivar páginas web. Usado en el almacenamiento de contenido web completo.
  • OGG-Vorbis: Formato de compresión de audio de código abierto. Usado en streaming y almacenamiento de audio.
  • WebM: Formato de video de código abierto. Usado en streaming de video en la web.
  • ISAAR CPF: Estándar para descripción de entidades de archivo. Usado en gestión de documentos y archivos.
  • ISAD (G) (General International Standard Archival Description): Estándar para descripción de archivos. Usado en archivística.
  • ISDF (International Standard for Describing Functions): Estándar para describir funciones en archivos. Usado en gestión documental.
  • NEDA (Norma Española de Documentación Administrativa): Estándar español para documentación administrativa. Usado en administraciones públicas.
  • UNE-ISO 30300, 30301, 15489, 23081: Estándares internacionales para gestión de documentos. Usados en sistemas de gestión documental.
  • SHA (Secure Hash Algorithm): Familia de funciones hash criptográficas. Usadas en seguridad de datos y firmas digitales.
  • LDAP (Lightweight Directory Access Protocol): Protocolo para acceder a servicios de directorio. Usado en autenticación y gestión de usuarios.
  • MIME (Multipurpose Internet Mail Extensions): Estándar para formatos de correo electrónico. Usado en el intercambio de mensajes y archivos.
  • SMTP (Simple Mail Transfer Protocol): Protocolo para enviar correos electrónicos. Usado en servidores de correo.
  • DNS (Domain Name System): Sistema para traducir nombres de dominio a direcciones IP. Usado en la navegación web.
  • HTTP (HyperText Transfer Protocol): Protocolo para transferencia de datos en la web. Usado en la comunicación entre navegadores y servidores.
  • IPSec (Internet Protocol Security): Protocolo para seguridad en comunicaciones IP. Usado en redes privadas virtuales (VPN).
  • CODICE: Estándar español para intercambio de documentos electrónicos. Usado en administraciones públicas.
  • Facturae: Formato de factura electrónica en España. Usado en la gestión de facturas electrónicas.
  • SCSP (Sistema de Consulta de Saldos de Proveedores): Sistema para consultar saldos de proveedores. Usado en administraciones públicas.
  • SICRES (Sistema de Intercambio de Cuentas y Registros Electrónicos): Sistema para intercambio de datos contables. Usado en administraciones públicas.
  • DCAT (Data Catalog Vocabulary): Estándar para catálogos de datos. Usado en la publicación de datos abiertos.
  • MoReq (Model Requirements for the Management of Electronic Records): Estándar para gestión de registros electrónicos. Usado en archivística.
  • PREMIS (Preservation Metadata Implementation Strategies): Estándar para metadatos de preservación digital. Usado en archivos digitales.
  • INSPIRE Metadata Regulation: Regulación para metadatos de información geográfica. Usado en sistemas de información geográfica.
  • N3 (Notation3): Formato para representar datos en RDF. Usado en la web semántica.
  • OWL (Web Ontology Language): Lenguaje para ontologías en la web semántica. Usado en la representación de conocimiento.
  • RDF, RDFa (Resource Description Framework, RDF in Attributes): Estándares para representar datos en la web semántica. Usados en la estructuración de información.
  • SKOS (Simple Knowledge Organization System): Estándar para organizar conocimiento. Usado en vocabularios controlados y tesauros.
  • SPARQL (SPARQL Protocol and RDF Query Language): Lenguaje para consultar datos RDF. Usado en la web semántica.
  • Turtle: Formato de sintaxis para RDF. Usado en la representación de datos en la web semántica.
  • XML (Extensible Markup Language): Lenguaje de marcado para estructurar datos. Usado en intercambio de información.
  • XSD (XML Schema Definition): Lenguaje para definir la estructura de documentos XML. Usado en validación de datos XML.
