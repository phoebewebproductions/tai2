ALGORITMOS

Definiciones

📝

Un Algoritmo es un conjunto ordenado y finito de operaciones que permite hallar la solución de un problema. No dependen del lenguaje de programación, y pueden expresarse en lenguaje natural, pseudocódigo o diagramas.

Características clave de los algoritmos:

  • Ordenado: indica el orden en que se ejecuta cada paso.
  • Finito: el algoritmo debe terminar en algún momento.
  • Determinista: si se sigue el algoritmo dos veces, se obtiene el mismo resultado.

Para problemas complejos, se utiliza el método "divide y vencerás", dividiendo el problema grande en porciones pequeñas que se puedan resolver individualmente.

Módulos, procedimientos y funciones

Los módulos son agrupaciones de pasos que resuelven un problema, facilitando la reutilización de código. Pueden recibir valores (variables) con los que operar para obtener un resultado.

🔄

Funciones

Reciben o no variables como parámetros de entrada y devuelven un único resultado.

Ejemplo:
función suma(a, b) {
  return a + b;
}
📋

Procedimientos

Pueden recibir variables de entrada y devolver varios, uno o ningún resultado.

Ejemplo:
procedimiento intercambiar(a, b) {
  temp = a;
  a = b;
  b = temp;
}
🔍

Variables Locales

Las variables declaradas dentro de procedimientos y funciones son Variables Locales, pertenecientes al contexto del subprograma.

🌐

Variables Globales

Las Variables Globales se definen en el ámbito del programa principal, aunque su uso está generalmente desaconsejado.

Cohesión y acoplamiento

🔄

Cohesión

Mide la relación entre las operaciones que ejecuta un módulo. Un módulo debe realizar una única tarea con un fin específico.

Módulo con alta cohesión
Tarea relacionada 1
Tarea relacionada 2
Tarea relacionada 3
🔗

Acoplamiento

Mide la dependencia entre módulos. Se busca el menor acoplamiento posible para facilitar la reutilización y el mantenimiento del código.

Módulo A
↔
Acoplamiento débil
Módulo B

Se debe buscar una alta cohesión en los módulos y un acoplamiento débil entre ellos.

Tipos de acoplamiento (de menor a mayor):

1
De datos
Comunicación mediante parámetros de datos simples.
2
De marca
Comunicación a través de estructuras de datos.
3
De control
Uso de variables de control en la comunicación.
4
Externo
Módulos ligados a componentes externos.
5
Común
Varios módulos referenciando un área común de datos.
6
De contenido
Un módulo accede o usa datos de parte de otro módulo.

Tipos de cohesión (de mayor a menor):

1
Funcional
Todos los elementos relacionados en una única función.
2
Secuencial
Empaqueta en secuencia varios módulos con cohesión funcional.
3
De comunicación
Elementos utilizan los mismos datos de entrada y salida.
4
Procedimental
Elementos relacionados que deben ejecutarse en un orden determinado.
5
Temporal
Tareas que deben realizarse en el mismo intervalo de tiempo.
6
Lógica
Tareas relacionadas de forma lógica.
7
Casual
Tareas con poca o ninguna relación entre sí.

Algoritmos recursividad vs iterativos. Backtracking

🔄

Algoritmos recursivos

Se llaman a sí mismos para resolver un problema. Tienen tres partes fundamentales: declaración, llamada recursiva y condición de parada.

Ejemplo: Cálculo del factorial
Función factorialRecursiva(n)
  Si n = 1 → devuelve 1
  Sino devuelve n * factorial(n-1)
🔁

Algoritmos iterativos

Utilizan sentencias iterativas (bucles) para resolver un problema.

Ejemplo: Cálculo del factorial
Función factorialIterativa(n)
  var resultado = 1
  while (n > 1) {
    resultado = n * resultado
    n = n - 1
  }
  Devuelve resultado
🔍

Backtracking

Algoritmo de vuelta atrás asociado al recorrido de pilas, colas y árboles. Enumera sistemáticamente todas las alternativas posibles en cada momento, probando una y manteniendo las demás en memoria.

A
B
D
E
C
F
G
Recorrido:
A → B → D → (vuelta atrás) → E → (vuelta atrás) → C → F → (vuelta atrás) → G
Dificultades del backtracking:
  • Evitar caer en bucles infinitos
  • Evitar evaluar demasiadas alternativas (consumo excesivo de memoria)
  • Pueden ser lentos en su ejecución
Soluciones:
  • Aplicar funciones heurísticas
  • Usar podas para limitar el número de llamadas al algoritmo

Algoritmos de ordenación y búsqueda

Algoritmos de búsqueda más importantes:

🔍
Búsqueda secuencial sin centinela

Recorre un array comparando todos los elementos hasta encontrar el buscado.

Complejidad: O(n)
🔎
Búsqueda secuencial con centinela

Añade el elemento a buscar al final del array para optimizar la búsqueda.

Complejidad: O(n)
🔦
Búsqueda binaria

Requiere un array ordenado. Compara el elemento buscado con el central y divide la búsqueda en mitades.

Complejidad: O(log n)

Algoritmos de ordenación más importantes:

🫧
Método de la burbuja

Compara pares adyacentes y los intercambia si no están ordenados.

Complejidad: O(n²)
🔍
Método de selección

Divide el array en parte ordenada y desordenada, seleccionando el menor elemento de la parte desordenada en cada iteración.

Complejidad: O(n²)
📥
Método de inserción

Toma elementos de la parte desordenada y los inserta en su posición correcta en la parte ordenada.

Complejidad: O(n²)
⚡
Quicksort

Divide la lista en dos partes usando un pivote, ordenando recursivamente cada parte.

Complejidad: O(n log n)
