1. ACCESIBILIDAD

La accesibilidad dentro del ámbito informático está enfocada en que todas las personas puedan acceder a los distintos servicios de una forma fácil e intuitiva.

1.1. ACCESIBILIDAD WEB

La accesibilidad web está enfocada en garantizar que las páginas web sean utilizadas por el mayor número de ciudadanos sin importar los conocimientos, las características del hardware utilizado y las capacidades personales.

"El poder de la Web está en su universalidad. El acceso por cualquier persona, independientemente de la discapacidad que presente, es un aspecto esencial."

- Tim Berners-Lee, inventor de la World Wide Web

1.1.1. BENEFICIOS DE UNA WEB ACCESIBLE

  • Incrementar la cuota de mercado y audiencia
  • Mejorar el acceso para personas mayores
  • Optimizar resultados en buscadores
  • Permitir reutilización de contenidos en múltiples formatos
  • Reducir la brecha digital
  • Mejorar eficiencia y tiempo de respuesta
  • Reducir costes de desarrollo y mantenimiento
  • Demostrar responsabilidad social
  • Reforzar imagen empresarial
  • Diferenciación competitiva
  • Cumplimiento legal
  • Aumentar productividad y crecimiento
  • Mejorar acceso a herramientas de información

1.1.2. PROCEDIMIENTO PARA CONSEGUIR UNA WEB ACCESIBLE

El World Wide Web Consortium (W3C) define las siguientes recomendaciones:

  1. Imágenes y animaciones: Usar el atributo alt para describir la función de elementos visuales
  2. Mapas de imagen: Usar mapas y texto del lado del cliente para puntos de acceso
  3. Multimedia: Incluir subtítulos, transcripciones de audio y descripciones de vídeo
  4. Enlaces: Usar texto significativo fuera de contexto (evitar "haga clic aquí")
  5. Organización: Usar encabezados, listas y estructura consistente con CSS
  6. Gráficos y tablas: Proporcionar resúmenes o usar atributo longdesc
  7. Scripts y complementos: Ofrecer contenido alternativo
  8. Frames: Usar noframes y títulos significativos
  9. Tablas: Asegurar lectura línea por línea coherente
  10. Validación: Usar herramientas y pautas W3C

1.1.3 ÁMBITOS DE APLICACIÓN DE LA ACCESIBILIDAD

Las recomendaciones según el tipo de discapacidad incluyen:

Discapacidad auditiva

  • Acompañar contenido sonoro con imágenes representativas
  • Proporcionar transcripciones de audio
  • Incluir subtítulos en videos
  • Ofrecer alternativas visuales para alertas sonoras

Discapacidad física

  • Permitir conexión de hardware adicional
  • Asegurar navegación por teclado
  • Proporcionar atajos de teclado
  • Diseñar interfaces que no requieran movimientos precisos
  • Dar tiempo suficiente para completar acciones

Discapacidad visual

  • Proporcionar descripciones de texto para imágenes
  • Asegurar suficiente contraste de color
  • Permitir redimensionar texto
  • Estructurar contenido para lectores de pantalla
  • Evitar contenido que parpadee o destelle
  • Ofrecer navegación consistente
