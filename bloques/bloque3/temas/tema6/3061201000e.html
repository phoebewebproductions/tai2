15. PERSISTENCIA

Persistencia del flujo de trabajo

La persistencia del flujo de trabajo es la captura duradera de un estado de la instancia de flujo de trabajo, independientemente de la información del proceso o del equipo.

Características principales:

  • Proporciona un punto de recuperación conocido en caso de error del sistema
  • Permite mover el estado de la instancia entre nodos en una granja de servidores
  • El proceso incluye:
    • Identificación de un punto de persistencia
    • Recopilación de datos a guardar
    • Delegación del almacenamiento al proveedor de persistencia

Implementación:

  • Requiere asociar un almacén de instancias a WorkflowApplication o WorkflowServiceHost
  • Utiliza SqlWorkflowInstanceStore para persistencia en SQL Server
  • Permite crear participantes de persistencia extendiendo PersistenceParticipant

Puntos de persistencia implícitos:

  • Al completar actividades TransactionScope o TransactedReceiveScope
  • Cuando una instancia se vuelve inactiva
  • Al finalizar o terminar una instancia
  • Al ejecutar una actividad Persist
  • Durante la ejecución interoperable con versiones anteriores

16. SEGURIDAD

Common Language Runtime (CLR) y .NET Framework proporcionan clases y servicios para:

  • Escribir código seguro
  • Personalizar permisos de acceso a recursos protegidos
  • Facilitar el uso de criptografía
  • Implementar seguridad basada en roles

Cambios en .NET Framework 4:

  • Las aplicaciones de escritorio se ejecutan como aplicaciones de plena confianza
  • Las aplicaciones de confianza parcial requieren espacio aislado
  • El sistema de permisos está superado por reglas de transparencia de seguridad

16.1 Seguridad de aplicaciones Web ASP.NET

Métodos de autenticación disponibles:

  • Windows:
    • Básica
    • Implícita
    • Autenticación integrada (NTLM o Kerberos)
  • Autenticación mediante formularios
  • Autenticación mediante certificados de cliente

16.2 Herramientas de seguridad (.NET Framework)

Principales herramientas:

  • Caspol.exe: Configuración de directivas de seguridad
  • Cert2spc.exe: Creación de certificados de software
  • Certmgr.exe: Administración de certificados
  • Makecert.exe: Generación de certificados X.509
  • SignTool.exe: Firma digital de archivos
  • Sn.exe: Creación de ensamblados con nombres seguros

16.3 Servicios criptológicos

Características principales:

  • Protección de datos contra visualización no autorizada
  • Mecanismos de detección de modificaciones
  • Comunicación segura en canales

System.Security.Cryptography:

  • Contenedores de CryptoAPI no administrada
  • Implementaciones administradas
  • Generación automática de claves

Métodos de cifrado compatibles:

  • Primitivos criptográficos
  • Cifrado de clave secreta y pública
  • Firmas digitales
  • Valores hash
  • Generación de números aleatorios
  • Manifiestos de ClickOnce
  • Compatibilidad con Suite B
  • Clases de criptografía de próxima generación (CNG)
