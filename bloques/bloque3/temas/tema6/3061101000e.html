11.1 TECNOLOGÍAS DE ACCESO A DATOS

Evolución de las tecnologías de Microsoft de acceso a las Bases de Datos:

ODBC (Open Database Connectivity)

  • Interfaz común de acceso a múltiples Bases de Datos usando SQL
  • Interfaz C++ de bajo nivel
  • Usa un driver específico para cada BBDD concreta
  • Permite conectar con cualquier base de datos con driver ODBC
  • Los creadores de las BBDD son responsables de crear drivers ODBC
  • Permite cambiar de BBDD sin recompilar ni modificar la aplicación

DAO (Data Access Object) y RDO (Remote Data Object)

  • Colección de objetos de más alto nivel que ODBC
  • Basado en el Motor Jet (Access)
  • Puede acceder a otras BBDD mediante conversión Jet a ODBC
  • RDO creado para usar directamente ODBC sin Jet

OleDB

  • Interfaz de acceso universal a datos (BBDD, ficheros, Exchange, Directorios)
  • Interfaz para lenguajes tipo C++

ADO (Active Data Object)

  • Arquitectura de objetos para simplificar el uso de OleDB
  • Utilizable en lenguajes tipo VB y de script
  • Puede usar OleDB u ODBC
  • Se basa en RecordSets conectados
  • RDS (Remote Data Sources):
    • Intento de mejorar ADO
    • Permite RecordSets desconectados

ADO.NET

  • Proporciona acceso a orígenes de datos:
    • Microsoft SQL Server y XML
    • Datos expuestos mediante OLE DB y ODBC
  • Características principales:
    • Separa el acceso a datos de la manipulación de datos
    • Los resultados se procesan directamente o se colocan en un objeto DataSet
  • Entity Framework:
    • Conjunto de tecnologías de ADO.NET para desarrollo orientado a datos
    • Permite trabajar con datos en forma de objetos y propiedades
    • Componente de .NET Framework

Componentes de ADO.NET

Proveedores de datos de .NET Framework:

  • Connection: proporciona conectividad a un origen de datos
  • Command: permite acceso a comandos de base de datos
  • DataReader: proporciona secuencia de datos de alto rendimiento
  • DataAdapter: puente entre el DataSet y el origen de datos

DataSet:

  • Diseñado para acceso a datos independiente del origen
  • Utilizable con múltiples orígenes de datos
  • Contiene colección de objetos DataTable con información sobre claves y relaciones

Modelo de programación

.NET unifica todos los modelos de programación ofreciendo:

  • Una única API
  • Un único entorno de ejecución
  • Un único conjunto de bibliotecas
  • Una única herramienta de desarrollo

Modelos de programación ASP.NET:

  1. ASP.NET Web Forms
    • Primer modelo de programación
    • Basado en eventos y controles
    • Favorece la productividad mediante programación declarativa
  2. ASP.NET MVC
    • Alternativa a Web Forms
    • Basado en el patrón MVC (Modelo, Vista, Controlador)
    • Integración con pruebas unitarias
    • Separación entre lógica de presentación, negocio y datos
  3. ASP.NET Web Pages
    • Modelo más reciente
    • Más simple y rápido de aprender
    • Mantiene toda la funcionalidad de ASP.NET

13. SERVICIOS

Aspectos importantes en el diseño de servicios:

  • Seguridad en transferencia de mensajes
  • Interoperabilidad
  • Modelos de mensajería
  • Gestión de excepciones

Mecanismos de seguridad en servicios Web XML:

  • Seguridad a nivel de transporte (SSL)
  • Seguridad a nivel del mensaje (WS-Security)

Modelos de intercambio de mensajes WCF:

  • Petición-Respuesta (síncrono)
  • Asíncrono (one-way)
  • Duplex

13.1 Servicios de Azure

Azure es un conjunto integral de servicios en la nube que incluye:

AZURE IAAS (Infraestructura como servicio)

  • Infraestructura segura y escalable
  • Despliegue de entornos híbridos
  • Protección de aplicaciones
  • Reducción de costes de infraestructura

AZURE PAAS (Plataforma como servicio)

  • Gestión del ciclo de vida de aplicaciones web
  • Modelo de pago por uso
  • Sin preocupación por mantenimiento de servidores

AZURE SAAS (Software como servicio)

  • Acceso a aplicaciones a través de Internet
  • Soluciones de software completas
  • Hardware y plataforma ofrecida por el proveedor

14. HERRAMIENTAS

Team Foundation Server (TFS)

  • Administración de código fuente
  • Gestión de proyectos
  • Compilaciones automatizadas
  • Pruebas y liberación
  • Cubre todo el ciclo de vida de la aplicación

Visual Studio.NET

IDE (Entorno Integrado de Desarrollo) con características:

  • Soporte para múltiples lenguajes .NET
  • Plataforma completa para Servicios Web
  • Desarrollo Rápido de Aplicaciones (RAD)
  • Diseñadores visuales
  • Depuración extremo a extremo
  • Tecnología Intellisense y Ayuda Dinámica

Herramientas de .NET Framework

Principales herramientas:

  • Al.exe: Assembly Linker para generar archivos con manifiesto
  • Caspol.exe: Herramienta de directiva de seguridad
  • Gacutil.exe: Herramienta Caché global de ensamblados
  • Ngen.exe: Generador de imágenes nativas
  • SignTool.exe: Firma digital de archivos
  • Sn.exe: Herramienta de nombre seguro
  • Winmdexp.exe: Herramienta de exportación de metadatos
