2.2. Historia de la arquitectura

La especificación original J2EE fue desarrollada por la empresa Sun Microsystems. Comenzando con la versión J2EE 1.3, la especificación fue desarrollada bajo el Java Community Process.

Evolución histórica

  • El SDK de J2EE 1.3 fue distribuida inicialmente como beta en abril de 2001.
  • La beta del SDK de J2EE 1.4 fue distribuida por Sun en diciembre de 2002.
  • La especificación Java EE 5 fue desarrollada bajo el JSR 244 y el lanzamiento final se hizo el 11 de mayo de 2006.
  • La versión Java EE 6 cumple la especificación JSR 316 y fue lanzada el 10 de diciembre de 2009.
  • La versión Java EE 7, cuya especificación es la JSR 342, de 28 de mayo de 2013.
  • La versión Java EE 8 September 21, 2017 y sigue la especificación JSR 366.

Plataformas de desarrollo hasta 2006

  • Java SE o Java Platform Standard Edition.
  • Java EE o Java Platform Enterprise Edition.
  • Java ME o Java Platform Micro Edition.

Para poder desarrollar arquitecturas multicapa o multinivel se hizo necesario el disponer de una nueva plataforma de desarrollo basada en Java, y por tanto apareció Java Enterprise Edition (JavaEE).

Especificación JavaEE

La especificación de JavaEE contempla:

  • Especificaciones para servidores de aplicaciones.
  • Un gran número de librerías en la que apoyarse para desarrollar sistemas complejos.
  • Manuales y buenas prácticas para poder formar a los equipos de desarrollo en la utilización de este tipo de sistemas.

Elementos de la plataforma Java EE 8

  • SDK (Software Development Kit) de Java EE.
  • Servidor de código abierto Glassfish.
  • Documentación de las APIs.
  • Ejemplos de código.
  • Tutoriales y manuales.
  • Una implementación de demo (Your first cup)
  • Test de compatibilidad para verificar si una plataforma es compatible con la especificación.
  • Java EE BluePrints, que son un conjunto de buenas prácticas y manuales para el desarrollo de aplicaciones multicapa. También contiene el conjunto de documentos que definen patrones de diseño y prácticas recomendadas en la creación de aplicaciones utilizando Java Enterprise Edition.
