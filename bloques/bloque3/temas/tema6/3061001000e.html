🌐 10.1 ASP.NET - Desarrollo Web

Las aplicaciones Web de Visual Studio se generan en torno a ASP.NET.

Características principales:

  • Es una plataforma para desarrollar y ejecutar aplicaciones en un servidor Web
  • Incluye:
    • Objetos y controles de tiempo de diseño
    • Un contexto de tiempo de ejecución
  • Forma parte de .NET Framework, proporcionando acceso a todas sus funciones
  • Los clientes Web se comunican a través de Servicios de Microsoft Internet Information Server (IIS)
  • Es la evolución de ASP (Active Server Page)
  • Permite el diseño y la programación WYSIWYG (What You See Is What You Get) de los WebForms

🔄 Ciclo de vida de una página ASP.NET

Cuando se ejecuta una página ASP.NET, ésta recorre un ciclo de vida en el que realiza una serie de pasos de procesamiento.

Fases principales:

🚀
Inicialización
🧩
Creación de instancias de controles
💾
Restauración y mantenimiento del estado
⚙️
Ejecución del código del controlador de eventos
🖥️
Representación

Eventos del ciclo de vida: Dentro de cada fase del ciclo de vida de una página, ésta produce eventos que puede controlar para ejecutar su propio código.
