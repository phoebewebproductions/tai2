4.1 SERVICIOS JAVA EE

La arquitectura Java EE ofrece una serie de servicios que son:

  • Servicio de nombres (Java Naming and Directory Interface - JNDI): ofrece acceso a componentes y recursos mediante nombres lógicos. Nos aporta: Portabilidad y mantenibilidad.
  • Servicio de transacciones (Java Transaction Service - JTS): se encarga de la ejecución de una serie de pasos de forma atómica y aislada mediante descriptores.
  • Servicio de seguridad (Java Authentication & Authorization Service - JAAS): implementa directivas de seguridad para recursos protegidos. Características principales: Control de acceso en dos pasos: autentificación y autorización.
  • Comunicación: distintas técnicas de comunicación, proporcionadas por el proveedor de servicio de aplicación o de contenedores. Existen dos modelos:
    • Comunicaciones Web: TCP/IP, UDP/IP, HTTP y HTTPS (con SSL/TLS)
    • Procesamiento de objetos distribuidos:
      • RMI (Remote Method Invocation)
      • Java Remote Method Protocol (JRMP)
      • CORBA-IIOP para interoperabilidad entre Java EE y sistemas CORBA
      • JAX-WS/JAX-RPC para interoperabilidad entre Java EE y Web Services
  • Persistencia: almacenamiento persistente de objetos y estados de objetos, normalmente realizado en bases de datos relacionales.

    Puede ser de dos tipos:

    • Declarativa: persistencia gestionada por el contenedor (CMP)
    • Programática: persistencia gestionada por bean (BMP) via API JDBC
  • Servicios de configuración y administración: empaquetamiento, instalación y configuración flexible de componentes y la administración de aplicaciones. Descripción mediante esquemas XML de las características de servidores, contenedores, aplicaciones, componentes y servicios.

4.1.1. Soporte Java para web services

La arquitectura presta una serie de servicios web (Web Services) para facilitar la comunicación entre las diferentes capas de la arquitectura:

  • JAXP: Procesamiento de documentos XML mediante modelo
  • JAX-RPC: permite llamada a procedimientos remotos mediante XML (se recomienda JAX-WS para nuevas versiones)
  • JAX-WS (Java API for XML Web Services 2.0): evolución de JAX-RPC
  • JAXB (Java Architecture for XML Binding): permite vincular objetos Java con datos en formato XML
  • JAXR (Java API for XML Registries): facilitar acceso a UDDI o ebXML
  • SAAJ (SOAP with attachments API for Java): generar y recoger mensajes SOAP
  • XMSS (XML and Web Services Security): seguridad a nivel de mensaje

4.1.2. Servicios Adicionales

  • JDBC: API estándar para conectar programas desarrollados en Java con SGBD
  • Java Persistence: API estándar para la gestión de la persistencia y el mapeo objetos/modelo relacional
  • JMS (Java Message Service): Estándar para la creación, recepción y lectura de mensajes
  • RMI (Java Remote Method Invocation): manera de tratar cliente-servidor (RPC)
  • Java IDL: permite a las aplicaciones Java EE invocar a objetos CORBA externos usando el protocolo IIOP
  • Java Mail Technology: API para leer, componer y enviar mensajes electrónicos
  • StAX (Streaming API for XML): Expone métodos para el procesamiento de documentos XML de forma iterativa
  • JAF (JavaBeans Activation Framework): Permite descubrir el tipo de datos de un objeto arbitrario
  • JACC (Java Authorization Service Provider Contract for Containers): Define un contrato entre servidor y proveedor de servicios
  • JCA (J2EE Connector Architecture): Módulos de SW para abstraer detalles de acceso a EIS
  • JMX (Java Management Extensions): API para crear sistemas de gestión y monitoreo
  • CORBA: permite crear objetos distribuidos, diferenciando stub y skeleton
