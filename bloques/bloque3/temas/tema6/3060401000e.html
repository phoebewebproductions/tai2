⚙️ 4.1 SERVICIOS JAVA EE

La arquitectura Java EE ofrece una serie de servicios que son:

📋 Servicio de nombres (Java Naming and Directory Interface - JNDI)

Ofrece acceso a componentes y recursos mediante nombres lógicos. Nos aporta: Portabilidad y mantenibilidad.

🔄 Servicio de transacciones (Java Transaction Service - JTS)

Se encarga de la ejecución de una serie de pasos de forma atómica y aislada mediante descriptores.

🔒 Servicio de seguridad (Java Authentication & Authorization Service - JAAS)

Implementa directivas de seguridad para recursos protegidos. Características principales: Control de acceso en dos pasos: autentificación y autorización.

🌐 Comunicación

Distintas técnicas de comunicación, proporcionadas por el proveedor de servicio de aplicación o de contenedores. Existen dos modelos:

  • Comunicaciones Web: TCP/IP, UDP/IP, HTTP y HTTPS (con SSL/TLS)
  • Procesamiento de objetos distribuidos:
    • RMI (Remote Method Invocation)
    • Java Remote Method Protocol (JRMP)
    • CORBA-IIOP para interoperabilidad entre Java EE y sistemas CORBA
    • JAX-WS/JAX-RPC para interoperabilidad entre Java EE y Web Services

💾 Persistencia

Almacenamiento persistente de objetos y estados de objetos, normalmente realizado en bases de datos relacionales.

Puede ser de dos tipos:

  • Declarativa: persistencia gestionada por el contenedor (CMP)
  • Programática: persistencia gestionada por bean (BMP) via API JDBC

⚙️ Servicios de configuración y administración

Empaquetamiento, instalación y configuración flexible de componentes y la administración de aplicaciones. Descripción mediante esquemas XML de las características de servidores, contenedores, aplicaciones, componentes y servicios.

🌐 4.1.1. Soporte Java para web services

La arquitectura presta una serie de servicios web (Web Services) para facilitar la comunicación entre las diferentes capas de la arquitectura:

JAXP: Procesamiento de documentos XML mediante modelo
JAX-RPC: permite llamada a procedimientos remotos mediante XML
JAX-WS: evolución de JAX-RPC
JAXB: permite vincular objetos Java con datos en formato XML
JAXR: facilitar acceso a UDDI o ebXML
SAAJ: generar y recoger mensajes SOAP
XMSS: seguridad a nivel de mensaje

🧰 4.1.2. Servicios Adicionales

JDBC: API estándar para conectar programas desarrollados en Java con SGBD
Java Persistence: API estándar para la gestión de la persistencia
JMS: Estándar para la creación, recepción y lectura de mensajes
RMI: manera de tratar cliente-servidor (RPC)
Java IDL: permite invocar a objetos CORBA externos
Java Mail Technology: API para leer, componer y enviar mensajes
StAX: Procesamiento de documentos XML de forma iterativa
JAF: Permite descubrir el tipo de datos de un objeto arbitrario
JACC: Define un contrato entre servidor y proveedor de servicios
JCA: Módulos de SW para abstraer detalles de acceso a EIS
JMX: API para crear sistemas de gestión y monitoreo
CORBA: permite crear objetos distribuidos
