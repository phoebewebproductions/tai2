9.1 LA ARQUITECTURA .NET

La respuesta de Microsoft al creciente mercado en entornos Web, como competencia a la plataforma Java de Sun Microsystems.

Características principales:

  • Nueva plataforma de desarrollo de software
  • Estrategia horizontal que integra todos sus productos
  • Amplio conjunto de bibliotecas de desarrollo
  • Entorno gestionado de ejecución de aplicaciones
  • Conjunto único y expandible de bloques interconectados
  • Establece XML como norma en el transporte de información

9.1.1 Infraestructura .NET

Está constituida por:

  • Framework .NET
  • Microsoft Visual Studio .NET
  • .NET Enterprise Servers
  • Microsoft Windows .NET

Framework .NET - Objetivos:

  • Entorno coherente de programación orientada a objetos
  • Proporcionar un entorno de ejecución de código seguro
  • Basar la comunicación en estándares del sector

9.1.2 Lenguajes de Programación

  • Soporta más de 20 lenguajes de programación
  • Principales lenguajes:
    • C#: Estándar de especificación ECMA334
    • Visual Basic
    • Delphi (Object Pascal)
    • C++
    • J#: lenguaje transicional para programadores Java y J++
    • Perl, Python, Fortran y Cobol.NET

9.1.3 Biblioteca de Clases Base (BCL)

Maneja las operaciones básicas en el desarrollo de aplicaciones, incluyendo:

  • Interacción con dispositivos periféricos
  • Manejo de datos (ADO.NET)
  • Administración de memoria
  • Cifrado de datos
  • Transmisión y recepción de datos (XML, TCP/IP)
  • Administración de componentes Web (ASP.NET)
  • Manejo de excepciones y seguridad
  • Sistema de ventanas y gráficos (GDI+)
  • Operaciones con tipos de datos, cadenas y fechas
  • Manipulación de archivos e imágenes

9.1.4 Entorno Común de Ejecución (CLR)

  • Entorno de ejecución para todas las aplicaciones .NET
  • Utiliza código intermedio (MSIL, Microsoft Intermediate Language)
  • Se basa en el Common Language Specification (CLS)
  • Usa compilador JIT (Just-In-Time) para generar código máquina
  • Proporciona independencia de la plataforma hardware
  • El código ejecutable se almacena en la memoria caché
