Como se ha visto en los apartados anteriores, las herramientas CASE tienen dentro de sus objetivos favorecer la tarea a los desarrolladores.

📊 3.1.1. GENERADOR DE CÓDIGO CON UML

Dentro de estas herramientas hay un subtipo que permite la generación automática de código por medio del UML.

El lenguaje UML (Unified Modeling Language) es un estándar que permite especificar y diseñar software basado en el paradigma de la orientación a objetos.

Existen en el mercado muchas herramientas que permiten traducir los distintos diagramas UML en código:

Argo UML

Genera código en C++, C#, Java, PHP4, PHP5, Ruby

Eclipse UML

Genera código Java

BOUML

Genera código C++, Java, PHP, IDL, Python, MySQL

🔄 3.1.2. GENERACIÓN DE CÓDIGO CON LENGUAJES DE 4ª GENERACIÓN (4GL)

Un lenguaje de cuarta generación (4GL) es una agrupación de lenguajes de programación que intentan acercarse al lenguaje humano, la forma de pensamiento y la conceptualización.

Algunos de los usos de los lenguajes 4GL:

Consultas de bases de datos

Generadores de informes

Manipulación de datos

Generadores de pantallas GUI

Desarrollo web

Lenguajes de propósito general

📝 3.1.3. DOCUMENTACIÓN

La documentación es una parte esencial de un buen desarrollo de un sistema porque permite:

  • Identificar la funcionalidad del software desarrollado.
  • Mejorar el proceso de mantenimiento.
  • Fomentar el uso de las herramientas desarrolladas por parte de los usuarios gracias a los manuales de usuario.

Mucha documentación está realizada mediante herramientas de índole técnica como puede ser:

  • Markdown. Lenguaje de marcado simple que permite redactar textos técnicos en un formato limpio online o sin conexión.
    • Mediante un sistema de etiquetado permite crear títulos, tablas e hipervínculos de una forma rápida y precisa.
