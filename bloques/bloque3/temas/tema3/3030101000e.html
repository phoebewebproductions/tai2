2. LENGUAJES DE PROGRAMACIÓN

2.1 DEFINICIÓN

💻

Un lenguaje de programación es un conjunto de comandos, instrucciones y otras reglas sintácticas usadas para crear un programa software.

De este modo, los programadores utilizan lenguajes "de alto nivel" para escribir un código. Ese código en alto nivel es entendible por los propios programadores. Después ese código es compilado a un lenguaje de "bajo nivel" que es interpretable por la máquina.

2.1 CARACTERÍSTICAS

Existen dos enfoques cruciales a la hora de entender un lenguaje de programación:

📏

Sintaxis

Se refiere exclusivamente al conjunto de reglas que definen lo que significan las distintas combinaciones de símbolos. Es decir, que el compilador es capaz de entender lo que el programador ha escrito. La solución de los errores sintácticos suele ser sencilla, ya que el propio compilador (o precompilador) detecta si existe algún error de este estilo, incluso antes de ejecutarlo (en tiempo de compilación).

🧠

Semántica

Se refiere al "significado" del programa. Es decir, responde a la pregunta ¿el programa, código o instrucción hace lo que espero que haga?, o si lo que se hace tiene sentido para el compilador.

2.3 TIPOS

Existen dos grandes tipos de lenguajes de programación:

⚙️

Bajo Nivel

  • Lenguaje máquina (código binario)
  • Ensamblador (entendible por máquinas y humanos)
📊

Alto nivel

  • Programación imperativa/estructurada:
    • C, Basic, Pascal
  • Programación funcional:
    • ML, Haskell
  • Lógica:
    • Prolog, LISP
  • Orientada a objetos:
    • Smalltalk, C++, .net, Ruby, Java, Python
  • Otros nuevos

Cada uno de estos lenguajes de programación tiene sus propias reglas. En el caso de C, además, tiene varios estándares reconocidos por ANSI:

📜
ANSI C89
📜
ANSI C90 (A efectos prácticos son el mismo lenguaje)
📜
ANSI C99
📜
ANSI C11
ℹ️

Por su compatibilidad con distintos Sistemas Operativos y su uso como estándar, las referencias en este tema se harán utilizando ANSI C89, pero hay que tener en cuenta que las preguntas sobre sintaxis o semántica pueden realizarse sobre cualquier lenguaje de programación.
