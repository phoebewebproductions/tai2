3.3 INSTRUCCIONES CONDICIONALES

🔀

Las instrucciones condicionales son aquellas en las que se evalúan una o varias instrucciones, pero solo una puede ser considerada cierta (true) y el resto falsas (false).

En C, las instrucciones condicionales son:

  • if
  • if..else
  • if anidados
  • if..else anidados
  • switch
  • switch anidados

Ejemplos de Instrucciones Condicionales

if (condición) {
    // Código a ejecutar si la condición es verdadera
    printf("La condición es verdadera");
}
if (condición) {
    // Código a ejecutar si la condición es verdadera
    printf("La condición es verdadera");
} else {
    // Código a ejecutar si la condición es falsa
    printf("La condición es falsa");
}
switch (expresión) {
    case valor1:
        // Código a ejecutar si expresión == valor1
        break;
    case valor2:
        // Código a ejecutar si expresión == valor2
        break;
    default:
        // Código a ejecutar si no coincide con ningún caso
}

3.3.1 BUCLES Y RECURSIVIDAD

🔄

Los bucles son sentencias que permiten que un bloque de código se ejecute varias veces, de forma secuencial.

En C, son estructuras de bucle:

  • while
  • for
  • do while
  • bucles anidados

Además permite, aunque no está recomendado: romper las estructuras de loop a través de:

  • break
  • continue
  • goto

Si no se incluye una condición de parada, se pueden dar bloques infinitos.

Ejemplos de Bucles

int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;
}
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
int i = 0;
do {
    printf("%d\n", i);
    i++;
} while (i < 5);

3.3.2. PROCEDIMIENTOS, FUNCIONES Y PARÁMETROS

📋

Una función es un grupo de sentencias que, todas juntas, ejecutan una tarea. En todo programa C debe existir al menos una función main(), que es la que se ejecuta por defecto.

Además, el programador puede crear tantas funciones como desee, teniendo en cuenta que cada función se compone de:

  • Parte declarativa: informa al compilador del nombre de la función, el tipo de datos que va a devolver y los parámetros que va a recibir.
  • Parte de definición: Es el cuerpo o conjunto de operaciones de la función.

Sintaxis de una Función

Tipo_devuelto nombre_de_la_funcion (lista de parámetros) {
    cuerpo de la función
}
  • Tipo_devuelto: Es el tipo de dato que devolverá la función. Si no devuelve nada será void.
  • Nombre_de_la_función: Es el nombre por el que se invocará la función.
  • Parámetros: lista de parámetros que reciba la función desde su invocante.

Si la función se declara static, quiere decir que solo puede invocarse desde el fichero en el que se ha definido.

Parámetros de Funciones

Si la función utiliza argumentos o parámetros, será necesario que se declaren los valores de esos argumentos. Dentro de la función se comportan como variables locales a la función, y cuándo termina la ejecución de la misma, se destruyen.

Las variables se pueden pasar por valor o por referencia. Por defecto, en C se pasan por Valor.

Por Valor

Las variables por valor son las que copian el valor del argumento en la variable de la función. Los cambios de la variable dentro de la función no tienen efecto fuera del ámbito de ejecución de la misma.

void incrementar(int x) {
    x = x + 1;  // Este cambio no afecta fuera de la función
}

Por Referencia

Las variables por referencia copian la dirección del argumento, por lo que las modificaciones de la variables sí tienen efecto fuera del ámbito de ejecución de la función.

void incrementar(int *x) {
    *x = *x + 1;  // Este cambio afecta fuera de la función
}

Diferencia entre Procedimientos y Funciones

La principal diferencia entre procedimientos y funciones es que las funciones devuelven un valor, mientras que los procedimientos no devuelven ninguno. Existen programas que distinguen la forma de declarar una función y un procedimiento. En C solo existen funciones. Lo más parecido a un procedimiento es declararlo de manera que devuelva un tipo void. Que no devuelvan un valor no quiere decir que el trabajo de un procedimiento no sea útil, ya que pueden modificar variables pasadas por referencia.

Función

int sumar(int a, int b) {
    return a + b;  // Devuelve un valor
}

Procedimiento (en C)

void imprimir(int a) {
    printf("%d\n", a);  // No devuelve valor
}
