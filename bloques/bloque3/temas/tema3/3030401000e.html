8 VECTORES Y REGISTROS

Los arrays son un tipo de estructura de datos que puede almacenar una colección de un número de elementos conocido y prefijado, todos del mismo tipo.

La forma de declarar un array es:

type arrayName [ arraySize];

Por ejemplo: double balance[10] quiere decir que balance es un array de 10 elementos de tipo double.

En C es necesario inicializar los arrays, ya que pueden contener valores "sucios" en memoria.

double balance[5] = {1000.0, 2.0, 3.4, 7.0, 50.0};

Para acceder a un valor del array, se utiliza la sentencia:

double salary = balance[3] //¿qué valor tiene salary?

Otras peculiaridades de los arrays son que:

  • C soporta Arrays multidimensionales
  • Los arrays se pueden pasar como parámetro por referencia a una función
  • Las funciones pueden devolver arrays
  • Se puede utilizar un puntero al primer elemento del array simplemente llamando por el nombre del array, sin utilizar el índice.

Por su lado, las estructuras permiten agrupar y combinar datos de diferentes tipos.

Y se pueden utilizar de la siguiente forma:

struct Books {
char  title[50];
char  author[50];
char  subject[100];
int   book_id;
} book;

Además, se pueden pasar por referencia como variable a una función. El puntero se definiría:

struct Books *struct_pointer;

Para acceder a la posición de memoria dónde se almacena el primer libro:

struct_pointer = &Book1;

Y para acceder a los miembros de una estructura:

struct_pointer→title;

9 ESTRUCTURA DE UN PROGRAMA

Un programa en C consiste, básicamente de:

  • Comandos de preprocesador
  • Funciones
  • Variables
  • Instrucciones y expresiones
  • Comentarios

En el ejemplo hello, world tenemos:

  • Los includes, que es un comando de preprocesador para invocar a otras librerías de C antes de comenzar a procesar el fichero actual.
  • Main() es la función principal, la primera que se ejecutara en el programación.
  • Los comentarios, entre /* … */, aunque también podrían haberse incluido con //
  • Las sentencias: printf
  • La finalización del programa: return

Una vez que se ha escrito un programa, es necesario compilarlo, y si no hay errores, se podrá ejecutar.
