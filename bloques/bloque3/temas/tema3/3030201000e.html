3 REPRESENTACIÓN DE TIPOS DE DATOS

Mientras los humanos utilizamos distintos tipos de conceptos de información, las máquinas solo pueden utilizar los valores lógicos 0 y 1 (sistema binario). El más utilizado por los humanos es el sistema decimal (del 0 al 9). Por lo tanto, se establecen agrupaciones de símbolos para representar más de los dos números del sistema binario.

Esto ocurre no solo con números, también con letras. El ordenador no es capaz de interpretarlas, por lo que se establece una codificación ASCII (American Standard Code for Information Interchange)

4 OPERADORES

Los operadores son los símbolos reservados por el lenguaje de programación para especificar una función lógica o matemática. Pueden ser:

  • Aritméticos
  • Relacionales
  • Lógicos
  • de Bit
  • de Asignación
  • Otros

Operadores de Asignación

Operador Descripción Ejemplo
= Asignación simple C = A + B asignará el valor de A + B a C
+= Suma y asignación C += A es equivalente a C = C + A
-= Resta y asignación C -= A es equivalente a C = C - A
*= Multiplicación y asignación C *= A es equivalente a C = C * A
/= División y asignación C /= A es equivalente a C = C / A
%= Módulo y asignación C %= A es equivalente a C = C % A

?: Operador ternario condición ? valor_si_verdadero : valor_si_falso

Precedencia de Operadores

La precedencia de operadores determina el orden en que se evalúan las operaciones. Aquí hay una lista simplificada de mayor a menor precedencia:

  1. () [] -> . :: Paréntesis y acceso a miembros
  2. ! ~ ++ -- + - * & (type) sizeof Operadores unarios
  3. * / % Multiplicación, división y módulo
  4. + - Suma y resta
  5. << >> Desplazamiento de bits
  6. < <= > >= Comparaciones
  7. == != Igualdad y desigualdad
  8. & ^ | Operaciones de bits
  9. && || Operaciones lógicas
  10. ?: Operador ternario
  11. = += -= *= /= %= &= ^= |= <<= >>= Asignaciones
  12. , Operador coma

Los operadores con mayor precedencia se evalúan primero. Cuando los operadores tienen la misma precedencia, se evalúan de izquierda a derecha, excepto las asignaciones que se evalúan de derecha a izquierda.
