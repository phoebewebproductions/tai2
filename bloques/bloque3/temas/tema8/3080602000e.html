6.2 PHP

PHP es un lenguaje de programación de uso general del lado del servidor originalmente diseñado para el desarrollo web de contenido dinámico.

Fue uno de los primeros lenguajes de programación del lado del servidor que se podían incorporar directamente en el documento HTML en lugar de llamar a un archivo externo que procese los datos.

El código es interpretado por un servidor web con un módulo de procesador de PHP que genera la página web resultante.

Características principales de PHP

  • Es considerado un lenguaje fácil de aprender
  • Es software libre
  • Es un lenguaje interpretado
  • Usa etiquetas de apertura y cierre: <?php y ?>
  • Tiene una amplia integración con bases de datos
  • Cuenta con una gran comunidad de desarrolladores
  • Ofrece un rendimiento optimizable mediante técnicas de caché

Funcionamiento de PHP

Cuando un cliente realiza una petición al servidor para que le envíe una página PHP, el servidor sigue estos pasos:

  1. Lee el archivo PHP del disco
  2. Identifica el código PHP entre las etiquetas especiales
  3. Procesa el código PHP
  4. Convierte el resultado en HTML
  5. Envía el HTML resultante al cliente

Variables predefinidas en PHP

  • $GLOBALS - Referencias a todas las variables disponibles en el ámbito global
  • $_SERVER - Información del entorno del servidor y de ejecución
  • $_GET - Variables HTTP GET
  • $_POST - Variables POST de HTTP
  • $_FILES - Variables de subida de ficheros HTTP
  • $_SESSION - Variables de sesión
  • $_COOKIE - Cookies HTTP
  • $_REQUEST - Variables HTTP Request
  • $_ENV - Variables de entorno

Novedades de PHP 8

  • Compilador JIT: Mejora el rendimiento compilando parte del código durante la ejecución
  • Union Types: Permite crear uniones de dos o más tipos de datos
  • Static return type: Permite usar static como tipo de retorno
  • WeakMap: Extensión para mejor gestión de memoria
  • Nuevas funciones string: str_contains, str_starts_with, str_ends_with
  • Función fdiv(): División segura que maneja división por cero
  • Mejoras en el sistema de tipos: Anotaciones de tipo más precisas

Paquetes de instalación PHP

  • X (multiplataforma)

  • MariaDB/MySQL (base de datos)

6.3 PERL

Practical Extraction and Report Language (PERL) es un lenguaje creado por Larry Wall en 1987.

Características principales:

  • Orientado inicialmente a administradores de sistemas
  • Basado en C y la programación shell de Unix
  • De propósito general
  • Open Source y multiplataforma
  • Especializado en tratamiento de texto
  • Eficiente en programación CGI
  • Usa DBI/DBD para interactuar con bases de datos
