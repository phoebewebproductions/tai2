📱 3.1 DISEÑO WEB MULTIDISPOSITIVO

El diseño web adaptable o diseño web adaptativo o responsivo (responsive web design) es una filosofía de diseño y desarrollo cuyo objetivo es adaptar la apariencia de las páginas web al dispositivo que se esté utilizando para visitarlas.

Hoy día las páginas web se ven en multitud de dispositivos como tablets, smartphones, libros electrónicos, portátiles, PC, etcétera.

Además, aún dentro de cada tipo, cada dispositivo tiene sus características concretas:

tamaño de pantalla
Resolución
potencia de CPU
sistema operativo
capacidad de memoria
otras

Esta tecnología pretende que con un único diseño web, todo se vea correctamente en cualquier dispositivo.

🔄 3.1.1 FRAMEWORKS RESPONSIVE WEB DESIGN

Se crea a partir de los artículos A List Appart de Ethan Marcotte, partiendo del concepto de One Web.

Es una técnica de diseño web que busca la correcta visualización de una misma página en distintos dispositivos. Desde ordenadores de escritorio a tablets y móviles. Contenido multiplataforma, multidispositivo.

Se trata de redimensionar y colocar los elementos de la web de forma que se adapten al ancho de cada dispositivo permitiendo una correcta visualización y una mejor experiencia de usuario.

Se caracteriza porque los layouts (contenidos) e imágenes son fluidos y se usa código media-queries de CSS3.

El diseño responsive permite reducir el tiempo de desarrollo, evita los contenidos duplicados, y aumenta la viralidad de los contenidos ya que permite compartirlos de una forma mucho más rápida y natural.

Podemos denominarlos Frameworks de front-end, o frameworks CSS.

Es una colección de herramientas para HTML, CSS y JavaScript que contiene patrones de diseño que pueden ser utilizados en la construcción de contenido de usuario cliente.

Descargan al desarrollador de perder tiempo en escribir código continuamente, así como ayudan a escribir código más optimo.

Permiten que el código resultante funcione adecuadamente en diversos dispositivos (multiplataforma, multidispositivo), incluyendo ordenadores de escritorio y portátiles, tables y teléfonos móviles.

Utilizan CSS media queries y mobile-first approach.

Se crean diseños unificados para una variedad de tamaños de pantalla, asegurando que el contenido es correcto independientemente del dispositivo.

A continuación exponemos algunos ejemplos de estos frameworks:

Simples

  • 1140 CSS Grid – optimo para monitores de 1080puntos.
  • Golden Grid System
  • Resposive Grid System, by Graham Miller
  • Columnal
  • Toast

Completos

  • Bootstrap

📏 3.1.2 MEDIA QUERY

En desarrollo web, las media queries son un módulo CSS3 que permite adaptar la representación del contenido a características del dispositivo como la resolución de pantalla (por ejemplo, un smartphone frente a pantallas de alta definición) o la presencia de características de accesibilidad como el braille.

Se convirtió en un estándar recomendado por la W3C en junio de 2012 y es un principio básico de la tecnología de Diseño web adaptativo (responsive web design).

Una media query consiste en un media type y una o más expresiones, que implican media features, que se resuelve en true o false.

El resultado de la consulta es verdadero si el media type especificado en el media query coincide con el tipo de dispositivo sobre el que el documento está siendo mostrado y todas las expresiones del media query son verdaderas.

Cuando un media query es verdadero, se aplica la hoja de estilo correspondiente o las reglas de estilo, siguiendo las reglas normales en cascada.

Un media type puede ser declarado en la cabecera de un documento HTML usando el atributo "media" dentro de un elemento <link>.

El valor específico del atributo "media" indica en que dispositivo el documento vinculado será mostrado.

Media types también pueden ser declarados dentro de instrucciones de procesamiento XML, el @import at-rule, y el @media at-rule. CSS2 definen los siguientes medias types:

braille
embossed
handheld
print
projection
screen
speech
tty
tv

El media type "all" también puede ser usado para indicar que las hojas de estilo apliquen todos los media types.
