4.3 WEB ESTÁTICA VS WEB DINÁMICA

Una página web estática es aquélla que no cambia cuando un usuario la solicita. El servidor Web envía la página al navegador sin modificarla.

Una página web dinámica es aquella cuyo comportamiento cambia con el tiempo o como respuesta a eventos producidos por la interacción del usuario.

Este dinamismo de la página se puede realizar o bien recurriendo a código que se encuentra en el Servidor Web o bien usando una combinación de HTML, CSS y Javascript desde el lado del Cliente.

Es decir, utilizando Tecnología del lado del Servidor o Tecnología del lado del Cliente.

Es habitual identificar como HTML Dinámico (DHTML) a todas las técnicas que se implementan desde el lado del Cliente.

Tecnologías del lado del servidor

  • ASP.NET: Tecnología orientada a crear páginas y aplicaciones web con .NET de Microsoft.
  • JSP: (Java Server Pages) Tecnología orientada a crear páginas y aplicaciones web con programación Java.
  • PHP: Es un lenguaje de programación del lado del servidor.
  • CGI: Interfaz de comunicación con programas que se ejecutan en el servidor, (por ejemplo en C o Perl). Estos programas pueden leer ficheros o bases de datos que están en el servidor normalmente. Esta tecnología ya está obsoleta, aunque todavía se puede encontrar en páginas web más antiguas.

Tecnologías del lado Cliente

  • HTML: Permite la definición de la estructura de las páginas web.
  • Hojas de estilo (CSS): Mediante las hojas de estilo podemos definir los valores de las propiedades que se aplicarán a las etiquetas/elementos HTML. Permite separar el modo de presentación de la página del contenido.
  • Javascript: Es un lenguaje de programación, interpretado por el navegador, que permite ejecutar instrucciones y manipular los elementos de la página. Captura y manejo de eventos Capacidad para asociar funciones JavaScript en respuesta a las acciones que realiza el usuario sobre la página Web.
  • Modelo de Objetos de Documento (DOM): Jerarquía de objetos incluida en los navegadores, que estructura los elementos de una página Web de acuerdo a una serie de clases y propiedades, modificables vía código.

WEB SEMÁNTICA

HTML5 intensifica la separación entre contenido y apariencia.

En HTML5 se eliminan algunos elementos relacionados con la presentación y se redefinen otros para que sólo tengan un contenido semántico.

Básicamente la web semántica propone la inclusión de metadatos semánticos que representan implícitamente algún tipo de información específica, para que pueda ser localizada por agentes informáticos, motores de búsqueda o aplicaciones a medida.

Esto permite una mejor clasificación del enorme volumen de datos que están siendo publicados en páginas web de internet.

En HTML5 se incluye la etiqueta <article>, recomendada para definir contenido que sea autónomo e independiente predecible de ser reutilizable como una entidad de información aislada.

Por ejemplo, si ese contenido puede ser redistribuido en RSS y sigue manteniendo íntegro su significado, entonces, probablemente el elemento <article> sea el contenedor apropiado para utilizar en nuestro documento. Cuando un navegador o motor de búsqueda localice etiquetas <article>, sabrá que en esa página hay contenidos que se pueden clasificar o indexar como unidades de información independientes.

Ventajas de la Web Semántica

  • Se mejora la accesibilidad e interoperabilidad de las páginas.
  • Se mejora la optimización para motores de búsqueda (SEO)
  • El código es más ligero y eso hace que las páginas sean más rápidas.
  • Gracias a estas nuevas etiquetas se puede generar una estructura de contenidos de una página que, antes de HTML5, apenas se podía definir por las cabeceras <h1>, <h2>… Pues los <div> no aclaraban nada sobre su contenido.
