5.1 JAVASCRIPT

JavaScript permite la generación dinámica de contenido HTML en el navegador. Existe una interacción con applets y plug-ins. Manejo de cookies del cliente.

Se ejecuta en general en el navegador del usuario (en el cliente) cuando al cargar la página, cuando sucede un evento (ejemplo: pulsar un enlace).

Tiene una funcionalidad limitada. En concreto JavaScript presenta sintaxis similar a java pero no es java 100%.

JavaScript es un lenguaje de programación posterior a Java, que surgió como propuesta de Netscape.

Características principales:

  • Extensión de HTML
  • Interpretado
  • Basado en prototipos
  • Es sensible a las mayúsculas y minúsculas
  • Java JDK 8 integra un motor de JavaScript

JavaScript normalmente depende del entorno en el que se ejecute. Su uso es más común para escribir funciones embebidas o incluidas en páginas HTML y que interactúan con el Document Object Model (DOM) o Modelo de Objetos del Documento) de la página.

Ejemplos de uso:

  • Cargar nuevo contenido para la página o enviar datos al servidor a través de AJAX sin necesidad de recargar la página
  • Animación de los elementos de página
  • Validaciones de primer nivel (ejemplo: formularios)
  • Transmisión de información sobre los hábitos de lectura de los usuarios y las actividades de navegación
  • Utilizar cookies en Javascript

5.1.1 FRAMEWORKS DE JAVASCRIPT

React

Es una librería de Facebook enfocada en la creación de vistas con particularidades como los patrones de eventos que permiten actualizar las mencionadas vistas cuando los datos hayan sido modificados, aportando una carga en tiempo real a nuestro desarrollo.

AngularJS 1.x y Angular 2.0+

Este framework fue creado y es promovido por Google. Angular 2.0 introduce grandes cambios respecto a su versión anterior, incluyendo el uso de TypeScript y una nueva API. Las versiones posteriores mantienen retrocompatibilidad.

VueJS

Vue fue creado por un ex-empleado de Google, que pretendía coger sus partes favoritas de AngularJS y crear algo muy ligero. Desde 2014 está disponible a toda la comunidad como proyecto Open Source.

NodeJS

Es un entorno en tiempo de ejecución multiplataforma, de código abierto, para la capa del servidor basado en el lenguaje de programación ECMAScript. Es asíncrono, con entrada y salida de datos en una arquitectura orientada a eventos y basado en el motor V8 de Google.

Fue creado con el enfoque de ser útil en la creación de programas de red altamente escalables, como, por ejemplo, servidores web.

Otros Frameworks

  • Meteor: Una plataforma completa que permite exportar código a diferentes entornos: web, mobile y desktop.
  • KOA: Nueva generación de framework web, más ligero y expresivo que Express.
  • SailsJS: Framework web con generador de acciones integrado.

5.1.2 APPLETS

Los applets son pequeños programas en JAVA que se ejecutan en el navegador. Pueden ejecutarse utilizando la Java Virtual Machine (JVM), o en el AppletViewer de Sun.

En Java, un applet es un programa que puede incrustarse en una página web. Cuando un navegador carga una página web que contiene un applet, este se descarga en el navegador web y comienza a ejecutarse.

Ventajas de los Applets

  • Son multiplataforma
  • Compatibilidad con múltiples versiones de Java
  • Pueden almacenarse en caché
  • Pueden tener acceso completo a la máquina con permiso del usuario
  • Rendimiento comparable a lenguajes compilados
  • Trasladan trabajo del servidor al cliente

Desventajas de los Applets

  • Requieren el plugin de Java (no soportado en Chrome ni Edge)
  • Tiempo de inicio de JVM
  • Acceso limitado al sistema si no están firmados
  • Restricciones de instalación en algunas organizaciones
  • Pueden requerir versiones específicas del JRE
  • Posibles vulnerabilidades de seguridad
  • Incompatibilidad con la mayoría de navegadores modernos
