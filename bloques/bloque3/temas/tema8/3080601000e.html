6.1 AJAX (ASYNCHRONOUS JAVASCRIPT AND XML)

AJAX son las siglas de Asynchronous JavaScript And XML, (Javascript asíncrono y XML).

No es en sí un lenguaje de programación, sino una nueva técnica que combina varios lenguajes de programación.

La ventaja de AJAX respecto a otros lenguajes de programación web es la asincronía. Esto consiste en que cuando queremos intercambiar datos con el servidor, la página no se queda parada esperando la respuesta, sino que se pueden seguir ejecutando acciones mientras tanto.

Componentes de AJAX

Ajax es una combinación de los siguientes lenguajes de programación y elementos:

  • HTML (o XHTML) y CSS: Base para el diseño de la página
  • DOM y Javascript: Forma de acceder dinámicamente a las partes de la página
  • Objeto XMLHttpRequest: Es el que permite la comunicación asíncrona con el servidor
  • XML: Formato en el que están los datos que se solicitan al servidor (aunque otros formatos también pueden funcionar)
  • PHP: O cualquier otro lenguaje de programación del lado del servidor

¿Cómo Funciona?

Con AJAX, al trabajar de forma asíncrona, permite que el usuario pueda seguir haciendo otras cosas o la página pueda mostrar otras cosas mientras se produce la respuesta.

A diferencia de usar solo PHP u otros lenguajes de servidor, donde la página permanece en espera mientras se procesa la petición, AJAX permite una experiencia más fluida al usuario.

Objeto XMLHttpRequest

Este objeto es fundamental para la programación con AJAX. Es una interfaz empleada para realizar peticiones HTTP y HTTPS a servidores Web.

Nos sirve tanto para incorporar datos en la página que tengamos en otros archivos del servidor, como para mandar datos de la página al servidor, y todo esto de forma asíncrona.

La diferencia entre utilizar XMLHttpRequest o simplemente utilizar PHP es que XMLHttpRequest permite mandar los datos en segundo plano, sin tener que parar el flujo de la página mientras se envían o reciben los datos.

6.2 JQUERY

JQuery es una biblioteca multiplataforma de JavaScript, creada inicialmente por John Resig, que permite simplificar la manera de interactuar con los documentos HTML, manipular el árbol DOM, manejar eventos, desarrollar animaciones y agregar interacción con la técnica AJAX a páginas web.

JQuery es software libre y de código abierto, posee un doble licenciamiento bajo la Licencia MIT y la Licencia Pública General de GNU v2.

Características de jQuery

  • Manipulación HTML/DOM
  • Manipulación de CSS
  • Métodos de eventos HTML
  • Efectos y animaciones
  • AJAX
  • Utilidades

Hay varias formas de comenzar a usar jQuery en una web:

  • Descargar la biblioteca jQuery de jQuery.com
  • Incluir jQuery de una CDN (Red de distribución de contenidos)

6.3 JSON (JAVASCRIPT OBJECT NOTATION)

  • Formato ligero de intercambio de datos
  • Simple de leer y escribir para humanos
  • Simple de interpretar y generar para máquinas
  • Los datos están encerrados entre llaves, las propiedades se separan por comas y los nombres preceden al valor, separados por dos puntos

6.4 TECNOLOGÍAS DE SERVIDOR

ASP (ACTIVE SERVER PAGES)

Características principales:

  • Tecnología propietaria de Microsoft
  • Usa lenguajes de script como Jscript o Vbscript interpretados
  • Superado por ASP.NET (framework desarrollo .NET)
  • Se ejecuta solo en servidores MS IIS

JSP (JAVA SERVER PAGES)

Características principales:

  • Abstracción de alto nivel de servlets de Java
  • Se traducen en servlets en tiempo de ejecución
  • Se puede utilizar como componente de vista en MVC
  • Puede entregar documentos HTML, XML y otros tipos de datos
  • El contenedor web crea objetos JSP implícitos
