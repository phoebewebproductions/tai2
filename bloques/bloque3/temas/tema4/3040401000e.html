4.1 DCL (LENGUAJE DE CONTROL DE DATOS)

🔐

Las operaciones de DCL permiten establecer trabajar con los permisos sobre las operaciones que se pueden realizar sobre la BBDD. Usualmente se utilizan para otorgar o revocar permisos de la base de datos a los usuarios.

4.1.1 GRANT

✅

Otorgar permisos

Otorga a los usuarios especificados el permiso sobre el objeto especificado.

GRANT permiso ON objeto TO Usuario
GRANT SELECT ON pedidos TO usuario1 [WITH GRANT]

Los permisos más utilizados son:

🔍
SELECT
➕

🎮

4.1.2. REVOKE

❎

Revocar permisos

Revoca a los usuarios especificados el permiso sobre el objeto especificado.

REVOKE permiso ON objeto TO Usuario
REVOKE SELECT ON pedidos TO usuario1

7. AMPLIACIONES DE SQL

🔄

Unos de los problemas que ha arrastrado SQL y por el que muchos usuarios ni siquiera lo consideran un lenguaje es que no dispone de los bloques de programación estructurada típicos como condicionales, bucles, secuencias de control, funciones, etc.

Esa carencia provoca que el lenguaje SQL sea utilizado habitualmente integrado en otro lenguaje de alto nivel como C, Java, C++, etc. El lenguaje de alto nivel efectúa la lógica de la aplicación y utiliza las llamadas de SQL para atacar a la base de datos.

Algunos fabricantes han creado sus propias extensiones de SQL añadiendo características de los lenguajes tradicionales al ANSI SQL. Estas características son exclusivas de cada lenguaje de tal forma que al utilizarlas el código queda ligado al fabricante del sistema gestor de bases de datos.

Los archivos de código se guardan en scripts SQL y pueden ser cargados en la base de datos o incluso almacenarse en ella.

Los lenguajes de SQL extendido más utilizados son:

🪟

Microsoft SQL Server

Transact SQL (TSQL)

🏛️

Oracle

PL-SQL
