2.1 CRIPTOGRAFÍA

La criptografía consiste en la alteración de la información mediante su combinación con otra información a la que denominamos clave. Existen los siguientes tipos:

🔐

Criptografía

Alteración de la información mediante su combinación con otra información a la que denominamos clave.

2.1.1 CRIPTOGRAFÍA SIMÉTRICA

La criptografía simétrica utiliza la misma clave para cifrar y descifrar la información, que deben conocer el emisor y el receptor de un mensaje, siendo este el punto débil del sistema, el intercambio de la clave, ya que en ese proceso la clave puede ser interceptada.

La criptografía simétrica se efectúa con los siguientes métodos:

Cifrado por bloques

El cifrado se ejecuta sobre grupos de bits de longitud fija denominados bloques. Se toma un bloque de texto plano como entrada y se devuelve un bloque cifrado de la misma longitud de salida. Este método tiene varios modos de operación:

Electronic codebook (ECB)

Los mensajes se dividen en bloques y cada uno de ellos es cifrado por separado utilizando la misma clave K.

Cipher-block chaining (CBC)

A cada bloque de texto plano antes de ser cifrado se le aplica una operación XOR con el bloque cifrado anterior. De esta forma, cada bloque de texto cifrado depende de todo el texto en claro procesado hasta este punto. Como no se dispone de un texto para el primer mensaje, se emplea un vector de inicialización.

Cifrado de flujo

En este modo no existen bloques, sino que un flujo de claves (keystream) opera sobre dígitos individuales. Existen las siguientes variantes:

Counter Mode (CTR)

Se usa un cifrado de bloque para producir el flujo de claves. Este flujo se combina con el texto plano mediante XOR dando lugar al cifrado. Para generar el flujo de claves se cifra un contador combinado con un número aleatorio (nonce) mediante ECB y se va incrementando.

Output Feedback (OFB)

El flujo de claves se genera cifrando el bloque anterior del flujo de claves, dando lugar al siguiente bloque. El primer bloque de flujo de claves se crea cifrando un vector de inicialización.

Cipher feedback (CFB)

Para producir el flujo de claves, cifra el último bloque de cifrado, en lugar del último bloque del flujo de claves.

Un ejemplo de uso de cifrado de flujo es el algoritmo ChaCha20, que usa claves de 128 y 256 bits.

2.1.2 CRIPTOGRAFÍA ASIMÉTRICA O DE CLAVE PÚBLICA

La criptografía asimétrica es el método criptográfico que usa un par de claves para el envío de mensajes. Las dos claves pertenecen a la misma persona que recibirá el mensaje. Una clave es pública y se puede entregar a cualquier persona, la otra clave es privada y el propietario debe guardarla de modo que nadie tenga acceso a ella. De esta forma se consigue:

🔒
Confidencialidad

Si se manda un mensaje cifrado con la clave pública del destinatario, sólo este será capaz de descifrarlo con su clave privada.

✅
Autenticación del emisor

Si el emisor cifra un mensaje con su clave privada, puede ser descifrado por cualquiera con su clave pública, y su relación con esta clave le identificará como el autor del mensaje.

Los sistemas de clave pública nacieron para resolver el problema del intercambio de claves en la criptografía simétrica. Los estándares de criptografía de clave pública se denominan PKCS (Public Key Cryptographic Standard) y especifican diferentes aspectos de esta técnica. Los más importantes son:

Estándar Descripción

PKCS #5 Estándar de cifrado basado en contraseñas
PKCS #7 Estándar sobre la sintaxis del mensaje criptográfico. Usado para la firma digital.
PKCS #11 Interfaz de dispositivo criptográfico
PKCS #12 Estándar de sintaxis de intercambio de información personal

El fundamento matemático de los algoritmos de cifrado asimétrico está en funciones de una sola dirección, en las que obtener un resultado desde un origen es fácil, pero obtener el origen desde el resultado es prácticamente imposible. De esta forma, se obtiene una clave a partir de la otra, pero no es posible realizar la operación inversa. Las funciones matemáticas en que se basan son:

🔢
Factorización de enteros

Se basa en que obtener un número mediante la multiplicación de números primos (factores) es fácil. Pero la operación inversa, obtener los factores primos de un número es muy difícil.

📊
Logaritmos discretos

Se basan en que la exponenciación en una operación fácil, pero su inversa, el logaritmo, es una operación difícil.

📈
Logaritmos discretos de curva elíptica

Es una variación del problema anterior más cara computacionalmente, lo que permite usar claves más pequeñas que mejoran las prestaciones de los algoritmos y reducen el tamaño de los textos cifrados.

El algoritmo RSA (Rivest, Shamir y Adleman) es un ejemplo de algoritmo de criptografía asimétrica de factorización de enteros y usa claves de 2048 y 4096 bits. El algoritmo ElGamal es otro ejemplo de criptografía asimétrica que usa logaritmos discretos. El algoritmo de Diffie-Hellman puede usar logaritmos discretos y logaritmos discretos de curva elíptica.

Algoritmo asimétrico Función matemática para generación de la clave
RSA Factorización de enteros
DSA Logaritmos discretos
ElGamal Logaritmos discretos
Diffie-Hellman Logaritmos discretos y de curva elíptica

2.1.3 CRIPTOGRAFÍA HÍBRIDA

La criptografía híbrida es un método que usa tanto el cifrado simétrico como el asimétrico. Emplea el cifrado asimétrico para compartir una clave para el cifrado simétrico. La clave de cifrado simétrico se cifra usando su propia clave privada, luego el mensaje cifrado se envía al destinatario. Ya que compartir una clave simétrica no es seguro, ésta es diferente para cada sesión.

Proceso de Cifrado Híbrido

🔑
Generación de clave simétrica de sesión
↓
🔒
Cifrado de la clave de sesión con clave pública del receptor
↓
📄
Cifrado del mensaje con la clave simétrica de sesión
↓
📦
Envío de la clave cifrada y el mensaje cifrado

PGP (Pretty Good Privacy) y GnuPG son ejemplos del uso de la criptografía híbrida.

3.2 FUNCIONES HASH

Una función hash o resumen tiene como entrada un conjunto de caracteres y lo convierte en otro conjunto de caracteres de longitud fija.

x -> h(x)

Funcionamiento de una Función Hash

Texto de entrada (longitud variable)
↓
🔄
Función Hash
↓
Resumen (longitud fija)

En criptografía las propiedades fundamentales de las funciones hash son:

🛡️
Resistencia a las colisiones

Dos grupos de caracteres diferentes no pueden tener el mismo resumen.

🔄
Función de un único sentido

Dado un resumen especificado, no se pueda encontrar la entrada que lo generó.

Las funciones hash se usan para detectar cambios en la información que se transmite. Al enviar un bloque de caracteres, se envía también su función hash, y si el mensaje es interceptado y modificado, puede detectarse al efectuar la función hash de lo que se recibe en el destinatario.

Funciones hash muy conocidas son:

3.3 ESTEGANOGRAFÍA

La esteganografía es una técnica que permite ocultar mensajes en objetos, denominados portadores, de forma que pasen inadvertidos. Existen numerosos métodos y algoritmos utilizados para ocultar la información dentro de archivos multimedia: imágenes, audio y video. Algunas de las técnicas más usadas son:

🕵️

Esteganografía

Técnica que permite ocultar mensajes en objetos, denominados portadores, de forma que pasen inadvertidos.

🖼️
Marcas de agua en imágenes

Enmascaramiento mediante marcas de agua en imágenes, con información de la propiedad intelectual, derechos de autor, etc.

🔍
Bit menos significativo (LSB)

Uso del bit menos significativo (LSB, Least Significant Bit) en cada pixel de una imagen digital para esconder un mensaje, de esta forma la distorsión de la imagen se mantiene al mínimo, y el mensaje se distribuye en todos sus pixeles.
