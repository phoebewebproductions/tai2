5.2 GESTIÓN REMOTA DE PUESTOS DE USUARIO

Como se ha visto en el epígrafe anterior, en algunas ocasiones, el técnico de soporte necesita conocer de primera mano las incidencias que se están produciendo en los equipos de los usuarios o prestar un apoyo para la ejecución de determinadas acciones.

🖥️

Gestión Remota

Conjunto de herramientas y técnicas que permiten a un técnico de soporte conectarse a un equipo de usuario a distancia para diagnosticar problemas, realizar mantenimiento o proporcionar asistencia sin necesidad de estar físicamente presente.

Para ello, el técnico puede utilizar determinadas herramientas o aplicaciones para conectarse al puesto de usuario, y, llegado el caso, controlarlo.

Arquitectura Cliente/Servidor

Las herramientas de gestión de puesto de usuario suelen ser del tipo cliente/servidor, por lo que requieren que previamente en el usuario se haya instalado la aplicación cliente, con la que se conectará el servidor instalado en el puesto de soporte.

Herramientas de Gestión Remota

A continuación se describen algunas de las herramientas más utilizadas para la gestión remota de puestos de usuario:

5.2.1 VNC (Virtual Network Computing)

VNC
Opensource

Se trata de una opción Opensource basada en una estructura cliente-servidor que permite observar las acciones del ordenador servidor remotamente a través de un ordenador cliente.

VNC no impone restricciones en el sistema operativo del ordenador servidor con respecto al del cliente: es posible compartir la pantalla de una máquina con cualquier sistema operativo que admita VNC conectándose desde otro ordenador o dispositivo que disponga de un cliente VNC portado.

Componentes de un sistema VNC

🖥️
VNC Servidor
Es el programa en el equipo que comparte su pantalla. El servidor de forma pasiva permite al cliente tomar el control de la misma.
👁️
VNC Cliente (o espectador)
Es el programa que vigila, controla e interactúa con el servidor. El cliente controla al servidor.
🔄
VNC Protocolo (RFB)
Es muy simple, basado en una primitiva gráfica del servidor al cliente y mensajes de eventos desde el cliente al servidor.

Funcionamiento de VNC

En el método normal de operación, un visor (espectador) se conecta a un puerto en el servidor (puerto por defecto 5900). Alternativamente, un navegador puede conectarse al servidor (dependiendo de la implementación) (puerto por defecto 5800). Y un servidor puede conectarse a un espectador en "modo de escucha" en el puerto 5500.

5900
Puerto por defecto para conexión cliente-servidor
5800
Puerto por defecto para conexión vía navegador
5500
Puerto para "modo de escucha"

Seguridad en VNC

⚠️

Por defecto, VNC no es un protocolo seguro. Como las contraseñas se envían en texto plano (como en telnet), el intento de romper o agrietar (cracking) la contraseña puede tener éxito si tanto la clave de cifrado y la contraseña cifrada es capturada desde una red.

🔑
Se recomienda utilizar una contraseña de al menos 8 caracteres.
🔒
Existen versiones comerciales que incluyen cifrado.

5.2.4 Escritorio remoto de Microsoft

Escritorio remoto de Microsoft
Incluido en Windows

Se trata de uno de los servicios de Microsoft, que está disponible en los equipos con sistema operativo Windows 10, excepto la versión Home. Esta herramienta permite la apertura de una sesión con usuario y contraseña en otro equipo con sistema operativo Microsoft.

⚠️

A diferencia de los programas anteriores, no se accede a la sesión de un usuario, sino que se abre una propia, y permite acceder al sistema y ejecutar aplicaciones.

5.2.5 Escritorio remoto de Chrome

Escritorio remoto de Chrome
Gratuito

Chrome Remote Desktop es una herramienta de software de escritorio remoto desarrollada por Google que permite a un usuario controlar de forma remota otro ordenador a través de un protocolo propietario desarrollado por Google llamado extraoficialmente "Chromoting".

Funcionamiento

Transmite los eventos del teclado y el mouse de un ordenador a otro, retransmitiendo las actualizaciones de la pantalla gráfica en la otra dirección, a través de una red.

🖥️
Componente de servidor
Para el ordenador de usuario donde se accede.
💻
Componente de cliente
En el ordenador que accede al ordenador remoto.

Evolución

Originalmente
El cliente de Escritorio remoto de Chrome era originalmente una extensión de Chrome de Chrome Web Store que requería Google Chrome.
↓
Actualmente
La extensión está obsoleta y hay un "portal" web disponible en remotedesktop.google.com.

Acceso

🌐

A través del portal web: remotedesktop.google.com

🔑

Requiere una cuenta de Google para la autenticación
