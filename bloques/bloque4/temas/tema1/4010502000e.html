5.2.2. WINDOWS ADK

Windows Assessment and Deployment Kit (Kit de evaluación e implementación de Windows) y el complemento de Windows PE es un conjunto de herramientas diseñadas a personalizar imágenes de Windows para la implementación a gran escala en equipos cliente o en imágenes de disco duro virutal (VHD). También permiten probar la calidad y el rendimiento del sistema, sus componentes agregados y las aplicaciones que se ejecutan en él.

Incluye:

  • El Kit de herramientas de evaluación de Windows y el Windows Performance Toolkit para evaluar la calidad y el rendimiento de los sistemas o componentes.
  • Herramientas de implementación como Windows PE, Sysprep y otras herramientas que puede usar para personalizar e implementar Windows 10 imágenes.
  • Windows de preinstalación (Windows PE) como una descarga independiente del Kit de evaluación e implementación (ADK).
  • También se le conoce como Windows Automated Installation Kit (Windows AIK o WAIK)

5.2.3. WINDOWS ADMIN CENTER

Windows Admin Center es la evolución de plataformas de administración tradicionales conocidas como el Administrador de servidores y la Microsoft Management Console (MMC). Se ha creado desde un principio pensando en la forma en que los sistemas se crean y administran hoy en día.

Contiene muchas de las herramientas familiares que se utilizan actualmente para administrar clientes y servidores de Windows Server asi como herramientas nuevas.

Permite administrar los servidores Windows Server sin ninguna dependencia de Azure ni de la nube. Complementa a System Center (no lo sustituye).

Se implementa localmente y se ejecuta en un explorador web.

Windows Admin Center ofrece el control total de todos los aspectos de tu infraestructura de servidores y es especialmente útil para la administración de servidores en redes privadas que no están conectadas a Internet.

Diagrama de Windows Admin Center funcionando con otras soluciones

Administra Windows Server 2019, Windows Server 2016, Windows Server 2012 R2, Windows Server 2012, Windows 10, Azure Stack HCI, etc.

Incorpora un componente opcional denominado Puerta de enlace de Windows Admin Center que permite administrar los servidores desde fuera de la red corporativa.

Para poder utilizar la puerta de enlace de Windows Admin Center debemos instalar el paquete ligero .msi incluído con Windows Admin Center en un servidor o un equipo Windows 10 unido al dominio.

A continuación debemos publicar en DNS y proporcionar acceso a través de los firewalls corporativos correspondientes.

Una vez instalada podremos conectarnos de forma segura y administrar a los servidores desde cualquier lugar con Microsoft Edge o Google Chrome.

La puerta de enlace administra servidores mediante PowerShell remota y WMI a través de WinRM.

Diagrama de la arquitectura de Windows Admin Center

Windows Admin Center funciona con soluciones como System Center y la administración y seguridad de Azure, y se agrega a sus funcionalidades para realizar tareas de administración detalladas en un solo equipo.

Características

  • Permite la administración desde cualquier lugar de forma segura mediante la instalación de la puerta de enlace de Windows Admin Center.
  • Seguridad mejorada para la plataforma de administración mediante un control de acceso basado en roles.
    • Permite ajustar con precisión qué administradores tienen acceso a cada característica de administración.
    • Las opciones de autenticación de puerta de enlace incluyen grupos locales, Active Directory basado en dominios locales y Azure Active Directory basado en la nube.
    • Permite obtener información útil acerca de las acciones de administración realizadas en tu entorno.
  • Integración de Azure.
  • Permite la implementación de clústeres hiperconvergidos y de conmutación por error a través de un asistente fácil de usar.
  • Permite la administración de clústeres hiperconvergidos
  • Extensibilidad: Microsoft ofrece un SDK que permite a los programadores crear sus propias herramientas para Windows Admin Center.

5.2.4. NAGIOS

Sistema de monitorización de redes ampliamente utilizado, de código abierto, que vigila los equipos (hardware) y servicios (software) que se especifiquen, alertando cuando el comportamiento de los mismos no sea el deseado y proporcionando una gran versatilidad para consultar prácticamente cualquier parámetro de interés de un sistema.

N.A.G.I.O.S. es un acrónimo recursivo: «Nagios Ain't Gonna Insist On Sainthood»

Entre sus características principales figuran:

  • Monitorización de servicios de red (SMTP, POP3, HTTP, NNTP, ICMP, SNMP).
  • Monitorización de los recursos de equipos hardware (carga del procesador, uso de los discos, logs del sistema) en varios sistemas operativos, incluso Microsoft Windows con los plugins NRPE_NT o NSClient++.
  • Monitorización remota, a través de túneles SSL cifrados o SSH.
  • Diseño simple de plugins, que permiten a los usuarios desarrollar sus propios chequeos de servicios dependiendo de sus necesidades, usando sus herramientas preferidas (Bash, C++, Perl, Ruby, Python, PHP, C#...).
  • Chequeo de servicios paralizados.
  • Posibilidad de definir la jerarquía de la red, permitiendo distinguir entre host caídos y host inaccesibles.
  • Notificaciones a los contactos cuando ocurren problemas en servicios o hosts, así como cuando son resueltos (a través del correo electrónico, buscapersonas, Jabber, SMS, o cualquier método definido por el usuario junto con su correspondiente complemento).
  • Posibilidad de definir manejadores de eventos que ejecuten al ocurrir un evento de un servicio o host para resoluciones de problemas proactivas.
  • Rotación automática del archivo de registro.
  • Soporte para implementar hosts de monitores redundantes.
  • Visualización del estado de la red en tiempo real a través de interfaz web, con la posibilidad de generar informes y gráficas de comportamiento de los sistemas monitorizados, y visualización del listado de notificaciones enviadas, historial de problemas, archivos de registros....
  • Originalmente se denominaba Netsaint.

Nagios fue originalmente diseñado para ser ejecutado en GNU/Linux, pero también se ejecuta bien en variantes de Unix.
