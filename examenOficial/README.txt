# Exam Generator for Technical Auxiliary in IT (T.A.I.)
#### Video Demo:  https://youtu.be/XiyKh-eGINg
#### Description:
This project is a web application designed to help candidates prepare for the **Technical Auxiliary in IT (T.A.I.)** exam. The app generates custom exams based on a question bank compiled from the past 8 years of actual exams, containing **497 questions**.

### Key Features:
- **Custom Exam Generation**: Users can select specific **subject blocks** or themes to create tailored exams. Questions are read directly from an **Excel file**, making the app flexible and easy to adapt to other exam specialties by simply changing the input file.
  
- **Results Report and Study Notes**: Upon completing an exam, the app generates a **detailed report** of the user's performance, which can be saved locally. If a question is answered incorrectly, the app produces **study notes** to help users review the material.

- **Recovery Exams**: Users can take **recovery exams** using only the questions they answered incorrectly in previous tests, reinforcing weak areas.

- **Performance Statistics**: The app tracks user performance and stores **statistics** locally. This allows users to analyze their progress over time and see which topics need more practice.

- **Color Palette Editor**: The app offers an **interface customization** feature, allowing users to change the color scheme, with the settings saved locally.

- **Mobile Optimization**: The app is fully optimized for use on **mobile devices**, offering a seamless user experience on the go.

### Adaptability:
The functionality of this app is not limited to the T.A.I. exam. By replacing the Excel file with a different question set, the app can be adapted for other exam preparations. All features, including result tracking, study notes, and performance analytics, will work with any new question bank.
